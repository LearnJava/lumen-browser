# BUG-1842 — самоблокировка `automation_hit_mismatch`: перехваченный клик автоматизации навсегда вешал поток `lumen-browser`

**Статус:** FIXED 2026-11-26 — guard документа освобождается до форматирования сообщения; перехваченный клик снова возвращает ошибку за доли секунды.
**Заведён:** 2026-11-26 (ZCode, задача «portal.nextera.ru: падение по «Войти», зависание клика, отрисовка полей, клик по панели»)
**Компонент:** shell ([`lumen/automation.rs`](../crates/shell/src/lumen/automation.rs))

## Симптом

Клик через automation (`click` по MCP `--mcp-live-port` или BiDi) по элементу, перекрытому другим, не возвращает
ответа: единственный поток, который раздаёт команды автоматизации, стоит на `Mutex` — соединение обрывается по
таймауту клиента. Найдено на `https://portal.nextera.ru/`: клик по строке агента в панели попадал в
`.pp-scrim` (слой-затемнение, [BUG-1844](BUG-1844-FIXED.md)), то есть уходил в путь перехвата.

## Причина

`automation_hit_mismatch` держал guard `source.document.lock()` живым до конца `match`. В ветке перехвата
`format!` вызывал `automation_node_label`, а тот берёт тот же лок (`let Ok(doc) = source.document.lock()`),
а `Mutex` не реентерабелен. Обе части — метка узла `<tag>#id (node N)` и лок внутри неё — появились в коммите
`0ed87805db` (2026-09-11, [BUG-1044](BUG-1044-FIXED.md)). В записи BUG-1044 сообщение перехвата тогда
получали, поэтому каким коммитом guard стал переживать `format!`, не устанавливалось.

## Исправление

Guard ограничен блоком, в котором вычисляется `hit_belongs_to_target`; наружу выходит `Option<hit_node>`,
и сообщение формируется после освобождения лока.

## Проверка

2026-11-26, живое окно (`--no-paint --viewport 800x600 --mcp-live-port`, портал без входа): кнопка
(`position: fixed; z-index: 2147483646`) под перекрывающим слоем (`inset: 0; z-index: 2147483647`), три клика
подряд:

```
Click error: Element click intercepted: point (360, 312) hits <div>#__occ_ovl (node 1348) instead of the target element (node 1346)
```

568 / 763 / 495 мс; после третьего окно отвечает на `eval`, паник в журнале 0. `cargo clippy -p lumen-shell
--all-targets -- -D warnings` чисто.

## Остаток

Юнит-теста на самоблокировку нет — она воспроизводится только на живом окне. Цифра `point (…, 312)` — на 42 px
ниже CSS-центра кнопки (270): сообщение печатает точку в координатах окна, а не страницы; не разбиралось.
