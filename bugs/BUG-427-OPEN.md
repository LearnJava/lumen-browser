# BUG-427 — вёрстка https://yandex.ru: блоки смещены, карточки пустые, поисковая строка наезжает на шапку

**Статус:** OPEN
**Компонент:** layout / paint (конкретное место не локализовано)
**Найден:** P1, 2026-07-28, при показе живого окна на реальном сайте
**Оговорка:** заводится как заявка на разбор, а не как локализованный дефект

## Симптом

Живое окно 1920×1080, https://yandex.ru (после редиректа — главная Дзена):

* поисковая строка нарисована поверх логотипа/шапки в левом верхнем углу;
* правая колонка — две пустые серые плашки вместо карточек;
* карточки ленты: два цветных прямоугольника без изображений, подписи под ними
  съехали относительно карточек;
* горизонтальный ряд ссылок шапки наложен сам на себя (несколько текстов в
  одной строке).

## Обязательное условие разбора

Значительная часть картины — следствие [BUG-423](BUG-423-OPEN.md) (пропадают
буквы из-за затирания сабсетов `unicode-range`): текст с дырами меняет ширины
строк и ломает перенос, поэтому «смещённые блоки» частично объясняются им.
**Переоценивать этот баг нужно после починки BUG-423** — возможно, часть
пунктов отпадёт, а остаток удастся локализовать нормально.

## Воспроизведение

```bash
cargo build -p lumen-shell --profile dev-release
./target/dev-release/lumen.exe --maximized https://yandex.ru
```

Для разбора без окна: `--dump-layout` / `--dump-display-list` по тому же URL,
`--trace-nav` для картины загрузки подресурсов.
