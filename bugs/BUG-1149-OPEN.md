# BUG-1149 — `connect` перебирает адреса по очереди, без Happy Eyeballs: `localhost` на Windows стоит ~2 с на каждое новое соединение

**Статус:** OPEN
**Заведён:** 2026-09-24 (P1, при WORKER-1 срез 5 — разбор новых TIMEOUT воркерных WPT-тестов)
**Область:** network (`crates/network/src/lib.rs::connect_inner` — прямой путь, цикл
`for addr in &addrs { TcpStream::connect_timeout(addr, CONNECT_TIMEOUT) }`; тот же цикл для
SOCKS5-прокси выше)
**Владелец:** P3.

## Симптом

Каждое новое TCP-соединение к `http://localhost:<port>/` при сервере, слушающем только IPv4
(wptserve, `python -m http.server --bind 127.0.0.1`, большинство локальных dev-серверов),
занимает ≈2,05 с. Лог `run_smoke.py` (2026-09-24): `→ GET …/utils.js` 0:47.18 → `← 200` 0:49.28;
закэшированный `testharness.js` — 10 мс. На странице это частично скрыто параллельной загрузкой,
а в воркере `importScripts`/синхронный `fetch`/XHR идут последовательно и складываются:
`fetch/api/basic/http-response-code.any.worker.html` отправляет свой единственный запрос уже
после 10-секундного тайм-аута харнесса, `xhr/getresponseheader.any.worker.html` (6 запросов)
не укладывается в тайм-аут — `TIMEOUT` вместо реального результата.

## Причина (проверено)

`getaddrinfo("localhost")` отдаёт `::1` первым, `127.0.0.1` вторым. Прямая проба (Python,
та же машина): `connect(::1, 8932)` → `ConnectionRefused` через **2,065 с** (Windows
повторяет SYN на отвергнутом loopback-порту), `connect(127.0.0.1, 8932)` → 0,015 с.
`connect_inner` пробует адреса строго последовательно и к следующему переходит только после
отказа первого.

## Ожидание

RFC 8305 (Happy Eyeballs v2): попытка следующего адреса стартует через ~250 мс после
предыдущей, не дожидаясь её отказа; выигрывает первое установленное соединение. Тот же
дефект на реальных сайтах — dual-stack хост с неработающим IPv6-маршрутом ждёт до
`CONNECT_TIMEOUT` (10 с) на каждом соединении.

## Не проверялось

- Linux/macOS (там отказ на loopback мгновенный, симптом на `localhost` не должен
  проявляться; на сломанном IPv6-маршруте — должен).
- H3/QUIC-путь (`crates/network/src/h3/`) — выбор адреса там отдельный.
