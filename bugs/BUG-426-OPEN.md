# BUG-426 — пять действий хрома разобраны в пустую ветку: профиль, режим Фокус, тема и вертикальные вкладки не переключаются из UI

**Статус:** OPEN
**Компонент:** shell (`crates/shell/src/main.rs:9807` — `dispatch_chrome_action`),
chrome (`assets/chrome/chrome.html`), генератор ассетов
(`scripts/gen_chrome_assets.py`)
**Найден:** P1, 2026-07-28, при разборе того, какие «подвиды» дизайна доступны
пользователю

## Симптом

Клик проходит хит-тест, действие резолвится — и не делает ничего. Пять
вариантов `ChromeAction` сведены в одну пустую ветку `=> {}`:

`SetProfile` · `ArchiveCard` · `ToggleSwitch` · `ToggleFocusTimer` ·
`ToggleFocus` · `SetDevtoolsTab`

Пользовательские последствия:

| Ось дизайна | Состояние |
|---|---|
| Профиль (Личный/Рабочий/Аноним/Гость) | поповер аватара открывается, выбор ничего не меняет |
| Режим Фокус | не включается |
| Тема (светлая/тёмная) | берётся только из тёмной темы ОС (`self.dark_mode`), в UI не переключается |
| Вертикальные/горизонтальные вкладки | состояние живёт и сохраняется (`vertical_tabs.visible`, `draft.tab_layout`), но единственный путь к нему — тумблер настроек, а он `ToggleSwitch` → [BUG-421](BUG-421-OPEN.md) |

При этом привязка состояний в DOM полностью готова: `bind_model`
(`crates/chrome/src/model.rs:570`) выставляет `body[data-theme]`,
`body[data-layout]`, `body[data-profile]`, а флип темы отдельно отслеживается
для перерисовки (`bind_model_tracked`, `["data-theme"]`). То есть не хватает
только обработчиков, а не поддержки состояний.

## Причина, зафиксированная автором среза

Комментарий на месте пустой ветки: все шесть тумблеров дизайна несут один и тот
же `data-action` без различающего атрибута, поэтому по одному `data-action`
нельзя понять, какую настройку переключили; структурный резолвер (по образцу
`chrome_permission_kind_for_node`) был вынесен за DoD среза.

## Что нужно сделать

1. В `scripts/gen_chrome_assets.py` проставлять различающий атрибут при
   инжекте — файл наш, генерация детерминированная (тем же приёмом, каким
   CC-13 инжектит `role`/`aria-*`).
2. Реализовать `SetProfile` (уже есть `ProfileRegistry`, DS-14) и `ToggleFocus`.
3. Дать теме UI-переключатель: `self.dark_mode` сейчас не имеет ни одной точки
   присваивания из UI.
4. `ArchiveCard` и `SetDevtoolsTab` — доработать или явно закрыть с
   обоснованием, если функциональности за ними нет.
