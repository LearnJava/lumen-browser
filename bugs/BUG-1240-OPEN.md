# BUG-1240 — `position: relative`: смещение утекает в поток, а при инкрементальной раскладке теряется

**Статус:** OPEN
**Тип:** корректность раскладки. Найден P1 при [BUG-1238](BUG-1238-FIXED.md), 2026-10-02.
**Область:** `crates/engine/layout/src/box_tree/layout_dispatch.rs` (смещение `position: relative`
через `shift_tree` в конце раскладки блока), инкрементальный путь `lay_out` для чистых поддеревьев.

## Симптом 1 — полная раскладка: смещение попадает в поток

```html
<body style="margin:0"><div style="height:50px"></div>
<div style="height:20px;position:relative;top:7px"></div><div style="height:30px"></div></body>
```

`layout()` отдаёт y = 0 / 57 / 77 и высоту `body` 107; по CSS 2.1 §9.4.3 относительное смещение
не влияет на соседей — ожидается 0 / 57 / 70 и 100. То же видно через JS: один `.rel` в списке
карточек увеличивает высоту родителя и сдвигает всех следующих братьев на `top`.

## Симптом 2 — инкрементальная раскладка: смещение чистого поддерева пропадает

12 карточек `div.c`, одна из них `position: relative; top: 3px; left: 2px`. Шаг 1: класс `rel`
на карточке. Шаг 2: `style.height` у другой, более поздней карточки. Полная раскладка того же
DOM даёт у карточки с `rel` координаты со смещением (2, y+3), а цепочка двух инкрементальных
флашей — без него (0, y) и высоту родителя без лишних 3 px. Карточка не менялась в шаге 2
(чистое поддерево), её `top`/`left` в `getComputedStyle` при этом верны.

## Гипотеза (не проверена)

Смещение `shift_tree(b, off_x, off_y)` записывается прямо в `rect` бокса. Быстрый путь
`lay_out` для чистых поддеревьев позиционирует бокс по курсору потока и не знает, что `rect`
содержит ещё и относительное смещение, поэтому либо теряет его, либо (в полной раскладке)
родитель двигает курсор от уже смещённого `rect`. Исправление — хранить смещение отдельно от
позиции в потоке (как у `sticky`/transform) либо применять его уже после того, как родитель
прочитал размеры.

## Как проверить

Вариант `relative_offsets` в `crates/js/src/dom/tests/v8_bug1238_scoped_collectors.rs` (см. git
history коммита BUG-1238: сценарий был убран, потому что расхождение — в раскладке, а не в
коллекторах) и `layout()`-проба из симптома 1.
