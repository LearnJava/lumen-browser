# BUG-435 — текст хрома терял буквы на yandex.ru; причина не установлена, симптом не воспроизведён

**Статус:** OPEN
**Компонент:** shell / paint (цепочка не установлена)
**Найден:** P1, 2026-07-28 (в составе [BUG-423](BUG-423-FIXED.md)), выделен
2026-07-29
**Приоритет:** низкий до повторной встречи — без воспроизведения чинить нечего

## Симптом (со слов исходной заявки)

Через несколько секунд после загрузки https://yandex.ru буквы пропадали не
только на странице, но и в UI браузера: `Костя · Личный` → `тя · Личны`,
`Восстановленная вкладка` → `т н вл нн я вк`.

## Почему это не [BUG-423](BUG-423-FIXED.md)

BUG-423 (bbox composite-глифа) объяснял и закрыл страничную часть симптома, но
к хрому он не применим:

* хром рисуется bundled-шрифтами (DS-4: `Golos Text`, `Golos Text Medium`,
  `JetBrains Mono`; `resolve_face_id` для них не спрашивает провайдера вовсе);
* у `assets/fonts/*.ttf` **нет ни одного** композита с вывернутым bbox —
  проверено разбором `glyf`: Golos Text Regular/Medium 306 композитов, Inter
  1881, JetBrains Mono 589, вывернутых 0.

## Состояние воспроизведения

Два живых прогона на https://ya.ru (до и после починки BUG-423, wgpu/DX12,
`--no-scrollbar`, 20 с) показали хром **целым**. Сам yandex.ru в этих прогонах
недоступен: он уводит на `sso.passport.yandex.ru` → `dzen.ru`, а страница
авторедиректа не выполняется (`form.submit is not a function`) и остаётся
пустой — то есть исходные условия заявки повторить не удалось.

## Кандидаты на проверку при следующей встрече

1. **Исчерпание атласа глифов.** `GlyphAtlas` — 1024×1024, shelf-packer без
   уплотнения; при `insert` без места возвращается `None`, а
   `Renderer::cached_glyphs` мемоизирует этот `None` **навсегда** (карта не
   чистится нигде) — глиф после этого не нарисуется уже никогда, в том числе в
   хроме. Эвикция есть только по внешнему memory-pressure. Симптом совпадает
   один-в-один: буква исчезает, advance остаётся. На синтетической странице
   (55 размеров × 119 символов) исчерпать атлас не удалось — нужна тяжёлая
   реальная страница; в код добавлялся временный счётчик отказов `insert`.
2. **Деградация после серии `set_font_provider`.** yandex.ru отдаёт 16 сабсетов
   одной семьи, то есть 16 вызовов подряд, каждый бампает `content_generation`
   и чистит `resolve_cache`.

## Как диагностировать

Временно логировать (a) отказ `GlyphAtlas::insert` по месту, (b) ветку `else`
в `push_text_glyphs`, где глиф не получил битмап — с `ch`/`face_id`/`gid`/
`size_bin`. Обе точки уже применялись при разборе BUG-423 и однозначно
разделяют «нет места в атласе» и «растеризация вернула None».
