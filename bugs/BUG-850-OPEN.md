# BUG-850 — радиус blur не ограничивается размером слоя: `backdrop-filter: blur(100000px)` рисуется 16 с вместо мгновенного, время линейно по радиусу

**Статус:** OPEN
**Заведён:** 2026-08-22 (WPT-RUN-6, срез 23 — найден прямым прогоном страниц, маркер `unclamped-blur` по измеренному списку id)
**Область:** `crates/engine/paint/src/cpu_raster.rs:1261` (`gaussian_blur` — `radius` считается из `sigma` и не сравнивается с размерами пиксмапа), `:1293` и `:1315` (`box_blur_h`/`box_blur_v` — прайминг аккумулятора `for i in -r..=r`, то есть O(r) на каждую строку/столбец и канал)
**Владелец:** P1/P3 (`lumen-paint`). Заведён P2 в ходе WPT-задачи, здесь не чинится.

## Симптом

```html
<div style="width:50px;height:50px;background:red"></div>
<div style="position:absolute;inset:0;width:100px;height:100px;
            backdrop-filter:blur(100000px)"></div>
```

`--screenshot` на этой странице выполняется **16 с** (обычная страница — доли
секунды). Ошибки нет, снимок в итоге получается; в прогоне WPT такая страница
просто TIMEOUT-ит и уносит с собой остаток шарда.

## Прямое измерение

2026-08-22, dev-release, Linux, коммит `3ae02b208`:

| страница | режим | время |
|---|---|---|
| `backdrop-filter: blur(100000px)`, 1024×720 | `--screenshot` | 16 с, `rc=0` |

## Причина (локализована чтением кода)

```rust
// cpu_raster.rs:1261
let radius = (((4.0 * sigma * sigma + 1.0).sqrt() - 1.0) / 2.0).round() as i32;
if radius <= 0 || w == 0 || h == 0 { return src.clone(); }
```

Верхней границы нет: `blur(100000px)` даёт `sigma = 50000` и `radius ≈ 50000`,
хотя слой не шире 1 024 px. Сам скользящий box-blur радиус-независим, но
аккумулятор перед каждой строкой набирается честным циклом по окну:

```rust
// cpu_raster.rs:1293 (box_blur_h), :1315 (box_blur_v)
let mut acc = 0.0f32;
for i in -r..=r { let idx = i.clamp(0, last) as usize; acc += src[...]; }
```

Это O(r) на каждую строку × 4 канала × 3 прохода × 2 оси — при r = 50 000 порядка
десятков миллиардов сложений, отсюда 16 с. Все выборки за краем всё равно
схлопываются в `clamp(0, last)`, то есть радиус больше размера пиксмапа
математически эквивалентен радиусу, равному этому размеру: ограничение
`r.min(w.max(h))` не меняет результат, но убирает весь лишний труд.

## Масштаб

**1 id** остатка снимка WPT-RUN-5 —
`/css/filter-effects/backdrop-filter-blur-large-value.html` (тест ровно про то,
что огромное значение должно вести себя как «всё размыто»). Механизм общий:
любая страница с большим радиусом `filter: blur()`/`backdrop-filter`/`box-shadow`
попадает под ту же цену.

## Проверка фикса

Страница выше должна укладываться и рисоваться за доли секунды; пиксели снимка
не должны измениться (клэмп радиуса до размера слоя математически эквивалентен).
Проверить дополнительно детерминированные CPU-снимки (`snapshot_cpu`) — они
содержат страницы с обычным blur, и их байты обязаны остаться прежними.
