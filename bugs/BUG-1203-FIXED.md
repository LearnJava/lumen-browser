# BUG-1203 — тест-бинарь `lumen-network` `tests/all.rs` проходит, но процесс не завершается

**Статус:** FIXED 2026-10-07 (join серверных потоков в bug785_extra_ca)
**Компонент:** network (`crates/network/tests/all.rs` — какой-то кейс оставляет живой не-daemon поток/сокет)
**Найден:** P3, в гейте `scripts/scoped-test.sh` к BUG-680, 2026-09-28

## Симптом

`cargo test -p lumen-network --test all` печатает
`test result: ok. 60 passed; 0 failed; … finished in 0.06s` — и процесс
`all-*.exe` дальше не выходит. Воспроизведено дважды на ветке, которая крейт
`lumen-network` не трогает (правка только в `lumen-js`): в полном
`scoped-test.sh` (висел >20 мин, снят вручную — cargo засчитал это как
`1 target failed: -p lumen-network --test all`) и отдельным прогоном под
`timeout 180` (rc=124 через 3 минуты после строки с результатом).

## Масштаб

`scoped-test.sh` втягивает `lumen-network` почти при любой правке (обратные
зависимости `lumen-js`), поэтому гейт P3/P1 без ручного вмешательства не
завершается вовсе, а после снятия процесса выглядит как провал.

## Дальше

Кандидаты — кейсы, поднимающие локальные серверы/потоки: `bug785_extra_ca::*`,
`nav_post_body::*` (они в хвосте вывода). Найти через `--test-threads=1` +
бисект по фильтру; кейс должен джойнить свой поток или закрывать listener.
