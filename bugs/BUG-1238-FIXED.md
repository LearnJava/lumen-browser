# BUG-1238 — flush читает устаревший rect у сдвинутых элементов (scoped-коллекторы)

**Статус:** FIXED 2026-10-02 (P1)
**Тип:** корректность (JS-видимая геометрия). Найден P1 при срезе 55 [BUG-935](BUG-935-OPEN.md), 2026-10-01.
**Область:** `crates/js/src/v8_runtime/style_flush.rs` (инкрементальная ветка `maybe_flush`),
`crates/engine/layout/src/lib.rs` (`collect_layout_rects_scoped`, `collect_client_rects_scoped`,
`collect_computed_styles_scoped`).

## Симптом

Принудительный reflow из JS возвращает у элемента, который сместился из-за правки соседа,
координаты до правки:

```html
<body style="margin:0"><div id="a" style="height:50px">a</div><div id="b" style="height:50px">b</div>
<script>
var a=document.getElementById('a'), b=document.getElementById('b');
a.getBoundingClientRect();              // первый flush — полный, создаёт базис
a.style.height='100px';
console.log(b.getBoundingClientRect().y);   // 50, ожидается 100
a.style.height='20px';
console.log(b.getBoundingClientRect().y);   // 50, ожидается 20
</script></body>
```

Проба: `lumen --dump-layout <файл>` (строки `[JS] …` в stderr). Результат на `main` @ e4690214a: 50 / 50.
Устаревшее значение живёт до следующего relayout шелла, который публикует полные карты.

## Причина

Инкрементальная ветка после раскладки собирает `layout_rects`/`client_rects`/`computed_styles`
только для поддеревьев `dirty_roots` (`collect_*_scoped`, BUG-1211 «post-collectors»). Док-комментарий
`collect_layout_rects_scoped` утверждает, что это корректно, «поскольку обход не разрешает значения
против геометрии предка» — неверно для абсолютных координат: бокс вне `dirty_roots` сдвигается, когда
меняется размер предшествующего брата (граф геометрии при этом переносит чистое поддерево целиком),
а запись в карте остаётся прежней. Эвикция `prev_node_ids` касается только самих корней.

Воспроизводится и без среза 55: при отключённом журнале содержимого те же 6 сценариев JS-теста
расходятся с полной раскладкой одинаково (расхождение — только у сдвинутых соседей).

## Исправление (2026-10-02)

После инкрементальной раскладки пересобирать записи для каждого бокса, чья геометрия изменилась:
обход нового дерева сверху вниз — корень `dirty_roots` собирается целиком; бокс из
`clean_subtrees` (`CounterMap`) пропускается, только если его собственный rect равен записи в карте
(иначе — сдвиг: собирается целиком); прочее (предки грязных корней) — спуск с пересчётом собственной
записи. Стоимость — O(сдвинутые + спина + дети спины); на стенде 1500 братьев, где сдвига нет,
это порядка сотен сравнений rect. То же для `computed_styles` (значения вроде `top`/`left` у
`position: relative`) и для `client_rects`.

## Как проверить

JS-тест среза 55 (`crates/js/src/dom/tests/v8_bug935_s55_content_journal.rs`) сравнивает режимы
журнал вкл/выкл между собой; для этого бага нужен вариант «инкрементальные flush'и против одного
полного» — те же `SCENARIOS`, но второй прогон без чтений между шагами.

## Что сделано

Вместо `collect_*_scoped` по поддеревьям `dirty_roots` — `lumen_layout::ScopedCollection`
(`crates/engine/layout/src/scoped_collect.rs`): план обходит свежее дерево сверху вниз.
Бокс из `dirty_roots` собирается целиком; бокс из `clean_subtrees` пропускается, если его
опубликованный rect совпал с записью в `layout_rects`, иначе собирается целиком (сдвиг);
остальные (предки грязных корней и всё, за что журнал не ручается) — собственная запись и
спуск. Записи пересобираются во временную карту и перезаписывают кэш — заодно ушли дубли в
`client_rects` у строчных элементов (`getClientRects()` у `<b>` накапливал по прямоугольнику
на каждый флаш).

Карта `computed_styles` дороже rect-коллекторов в ~100 раз (~1 с на 1500 div), поэтому
сдвинутое чистое поддерево пересобирается в ней, только если сдвиг мог изменить used-значения:
изменились `x`/размер корня, `x`/ширина родителя либо внутри есть позиционированный бокс
(`translation_keeps_styles`). Чисто вертикальный сдвиг карту не трогает.

Тест — `v8_bug1238_scoped_collectors` (цепочка инкрементальных флашей против одной полной
раскладки, 7 сценариев) и три юнита `scoped_collect::tests`. Остаток: расхождение полной и
инкрементальной раскладки у `position: relative` — [BUG-1240](BUG-1240-FIXED.md).
