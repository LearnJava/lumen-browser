# BUG-1350 — Пустой блок (`height: 0`, без содержимого) не схлопывает свои верхнее и нижнее поля друг с другом («collapse through», CSS 2.1 §8.3.1) — соседние поля складываются, а не сводятся к наибольшему

**Статус:** OPEN
**Заведён:** 2026-10-07 (P2, WPT-RUN-14 срез 12, `css/CSS2` (normal-flow + margin-padding-clear))
**Область:** layout (`crates/engine/layout/src/box_tree/bfc.rs`, `block_flow_trampoline.rs` — схлопывание полей пустого блока)

## Симптом

`--dump-layout`, `body{margin:0}`: `<div height:10px; margin-bottom:20px>` + `<div height:0; margin:20px 0>` + `<div height:10px; margin-top:20px>`. Получено: пустой блок на `y=30`, третий на **`y=50`** (30 + нижнее поле 20). Ожидается `y=30` (все три поля — 20, 20, 20 — сводятся к одному 20). Две пустые строки подряд между блоками с полями — то же (`y=110` вместо `y=90`). Страница `margin-collapse-016.xht` повторяет схему: `#div4` на `y=125.72` вместо `85.72`.

## Как найдено

WPT-RUN-14 срез 12: `margin-padding-clear/margin-collapse-{016,019,026,110,111,112,113,114,115,116,155}`, `margin-collapse-clear-*`, `margin-collapse-min-height-*`, `normal-flow/margin-collapse-*` — 30 id в кластере «margin collapse» (по правилу «первое совпавшее»); проба подтверждена на 016. A/B не делался: поправка в движке, а не в разметке. Часть id — другой механизм (см. ниже), так что число — верхняя граница.

Отдельный случай внутри кластера: `margin-collapse-137/138.xht` — `position:relative; margin:0 0 5em` с единственным `position:absolute` потомком. Относительный бокс садится на `y=108` (сдвиг схлопнутого нижнего поля учтён), а абсолютный потомок остаётся на `y=8` (посчитан до сдвига); containing block потомка — именно этот бокс.

## Что делать

В `bfc.rs` схлопывать верхнее и нижнее поле блока без содержимого и высоты (`height: auto/0`, без рамок/padding, без line box) в одно и затем с соседями; для абсолютных потомков такого бокса пересчитывать позицию после применения сдвига от схлопнутого поля.

## Как проверить

`css/CSS2/margin-padding-clear/margin-collapse-016.xht`, `margin-collapse-137.xht`.
