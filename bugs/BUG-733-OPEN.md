## Как воспроизводить

`lumen --mcp-live-port N about:blank` → `navigate` → `wait document_ready` →
выдержка ≥25 с → `resources/read`. `file://`/`https://` стартовым CLI-аргументом
не работают ([BUG-651](BUG-651-OPEN.md)).

Эталон: `msedge --headless=new --disable-gpu --hide-scrollbars
--window-size=1024,720 --virtual-time-budget=25000 --screenshot=<абсолютный
путь>` (относительный путь Edge молча не пишет).

## Ловушки (проверено на этой странице)

* **`getComputedStyle`/`getBoundingClientRect` по inline-элементам врут** —
  пустой `display` и нулевой rect у ~900 из 2242 элементов, это
  [BUG-488](BUG-488-OPEN.md) (у inline-элемента нет своего `NodeId`), а не
  отсутствие бокса. Геометрию смотреть `--dump-layout`/`resource://layout`.
* **Отсутствие CSS-запросов в `resource://network` ничего не значит** — лог не
  содержит ни главного документа, ни таблиц стилей, которые шелл тянет на этапе
  разбора HTML. Проверять применение стилей, а не факт запроса.
* **`data-href` вместо `href` у 14 из 25 `<link rel=stylesheet>` — не дефект**:
  Edge оставляет их ровно так же (сверено `--dump-dom`), стили этих компонентов
  приходят инлайн-блоками `<style>` (275 КБ на странице). Не начинать разбор с
  гипотезы «не загрузились стили».
* `document.styleSheets`, `document.images`, `Element.attributes`,
  `Node.contains` в шиме отсутствуют ([BUG-732](BUG-732-OPEN.md)) — проба,
  начинающаяся с них, падает целиком.
* Часть аналитических доменов режется DNS/TLS (класс
  [BUG-657](BUG-657-OPEN.md)) — фон, не причина.
