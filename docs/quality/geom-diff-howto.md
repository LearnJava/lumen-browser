# Geometry/computed-styles diff против Chrome — как запускать и читать

Скрипт `scripts/geom_diff.py` (TEST-11) отвечает на вопрос «страница разложена так же, как в Chrome?»
по координатам и computed styles, до растеризации: пиксельный дифф против Chrome шумит на шрифтах
и антиалиасинге, а `getBoundingClientRect` показывает расхождение раскладки напрямую.

## Запуск

```
python scripts/geom_diff.py --lumen <путь>/target/dev-release/lumen.exe      # весь корпус, ≈ 15 мин
python scripts/geom_diff.py --only hn rust --out .tmp/gd.md                    # часть корпуса
python scripts/geom_diff.py --reuse                                            # пересравнить снимки без браузеров
python scripts/test_geom_diff.py                                               # тесты логики сравнения
```

- Корпус — [`geom-corpus.txt`](geom-corpus.txt) (`slug url`; 14 сайтов перф-корпуса + 6 из
  `docs/perf/corpus-top100-foreign.txt`).
- Lumen: живое окно `--bidi-port` + `--viewport 1280x720`, `LUMEN_NO_ADBLOCK=1`. Viewport задаётся
  флагом, потому что `browsingContext.setViewport` в `lumen-bidi-server` только запоминает размер, окно
  не меняет (`bc_set_viewport`, `crates/bidi-server/src/protocol.rs`).
- Chrome: `--chrome` > `$CHROME_BIN` > самый новый Playwright Chromium > установленный Chrome;
  headless, CDP, `Emulation.setDeviceMetricsOverride` 1280×720 DPR 1, UA без `HeadlessChrome`,
  `Emulation.setScrollbarsHidden` — полоса прокрутки Lumen не отнимает ширину у страницы
  (`clientWidth` = 1280 на прокручиваемой странице), классическая полоса Chrome отнимает 15px,
  без выравнивания сдвигается всё, что выровнено по центру или справа.
- Снимок: `document.readyState == complete` → инжект `animation/transition: none` и `scrollTo(0,0)` →
  `--settle` (2 с) без изменения числа элементов (не дольше 20 с) → `SNAPSHOT_JS`. Один и тот же
  синхронный сниппет в обоих браузерах (`script.evaluate` Lumen не ждёт промисы).
- Сырые снимки — `.tmp/geom_diff/<slug>.<браузер>.json`; отчёт — `docs/quality/geom-diff-<дата>.md`,
  сводка для машин — `geom-diff-<дата>.json` рядом.

## Что в снимке

Обход `body` в порядке документа; `script/style/link/meta/template` пропускаются, поддерево
`display:none` не обходится (ключ попадает в `hidden`). Ключ — путь `tag:nth-of-type` от `body`
(`body>center:1>table:1>tbody:1>tr:3`). Подробно (прямоугольник с округлением 0.5px + срез `display`,
`position`, `font-size`, `font-family`, `visibility`, `overflow`) — до `--limit` (500) узлов, чей
прямоугольник пересекает область 2×viewport; ключ и прямоугольник остальных отрисованных узлов — в
коротком списке `all` (до 8000).

## Как читать отчёт

Δ = Lumen − Chrome. Узел расходится, если хоть одна из |Δx|, |Δy|, |Δw|, |Δh| больше порога (4px)
или не совпал срез стилей (`16.0px` = `16px`, у `font-family` сравнивается первое имя).

- **Сматчено** — доля ключей, подробно описанных в обоих снимках, из всех подробно описанных хоть в
  одном (без «за лимитом»: узел есть у второго браузера, но его лимит кончился раньше).
- **Геометрия (корней / блочных)** — расходящиеся узлы; корень — узел, чьё расхождение не объясняется
  окружением: сдвиг не равен сдвигу родителя или «предыдущий сосед + разница его размера»,
  ширина не следует за родителем, высота не объясняется расходящимся ребёнком. Топ-10 корней —
  сначала блочного уровня: x и ширина строчных (`display: inline*`) боксов зависят от ширины текста
  вокруг, это чаще метрики шрифта, чем раскладка.
- **Нулевой rect у Lumen** — `getBoundingClientRect()` у Lumen `0,0,0,0`, у Chrome нет; отдельный
  класс, в геометрию не входит.
- **Узел вне области** — у одного браузера узел в 2×viewport, у другого ниже/правее: считается
  геометрией (`у lumen вне области`), а не «деревом».
- **Дерево разошлось** — ключ есть в одном снимке и отсутствует в другом: `нет в DOM` (упавший JS,
  другая разметка, A/B-тест сайта), `display:none` / `внутри display:none` (стилевое решение второго
  браузера). Печатаются корни поддеревьев с числом узлов.
- **Итог** — «N сайтов из M без расхождений (не сняты: K)»: сайт без расхождений — ноль по геометрии,
  нулевым прямоугольникам, стилю и дереву.

Chrome — не абсолютный эталон: спорные случаи решает спецификация/WPT, в отчёте они помечены «spec?».
Живые сайты меняются между загрузками (ротация новостей, реклама, A/B): одиночные расхождения
«нет в DOM» на новостных сайтах сначала перепроверить повторным прогоном.
