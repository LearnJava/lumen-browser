# Приоритетная очередь багов (T0–T3)

Составлено 2026-08-23 по запросу «видимое движение в прогрессе браузера». Порядок очередей
`STATUS-P1.md`/`STATUS-P3.md` выведен из этого документа; при расхождении правду пишут здесь,

## Принцип

Тесты WPT падают не из-за тестов, а из-за пробелов движка. Порядок = «масса задетых тестов ×
заметность для пользователя ÷ размер фикса». Один починенный механизм часто зеленит сразу
десятки тестов (методология `docs/wpt-status.md`: BUG на первопричину, не на тест).

| Тир | Смысл |
|---|---|
| **T0** | Блокеры честного измерения и крупнейшие массы падающих тестов |
| **T1** | Сайтоломательное: висяки, вечные циклы, OOM, циклы перезагрузок |
| **T2** | Массовые механизмы из аудита WPT-RUN-6 — быстрые победы (фикс мал, тестов зеленит много) |
| **T3** | Остальное (layout/paint/css-хвост) в прежнем относительном порядке |

Внутри тира порядок стабилен (по строке в `BUGS.md`) — новые находки дописывать в конец своего
тира, не перемешивать.

## T2 — массовые механизмы аудита WPT-RUN-6 (быстрые победы)

Диагностированы срезами 15–24 (репродукция и call-site уже в файлах багов) — это самые дешёвые
«+десятки зелёных тестов» за коммит:

- **P1:** BUG-591 (глотание исключений, немые механизмы), 661/807 (первая доставка Resize/IntersectionObserver),
  772–777 (WebSocket-порты, Storage-Proxy, StorageEvent, track load/error, воркеры), 796 (`meta.content`),
  808/813/815 (Animation-EventTarget, worker onerror/таймеры), 821–828 (scroll/scrollend, Streams tee/BYOB,
  медиа-шим, preload-хинты без запросов, MutationObserver мимо парсера, WebAudio-тишина), 829/831/832
  (pushState-Location, строковые таймеры, sync-hashchange), 834/837–839/841–848/851/853/854
  (unload, activation-предок, script src="", resource-timing, IDB-очереди, CompressionStream-флаш,
  long-коэрция, `<details>` toggle, `<frame>`).
- **P3:** BUG-848 (запрос картинки только с `<img>`), 850→см. T1, 852 (content-visibility события),
  803→см. T1.
