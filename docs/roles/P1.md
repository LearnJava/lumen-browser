# Программист 1 (P1) — памятка роли

Проект — **Lumen**, браузер на Rust с собственным движком. Корень — каталог репозитория
(у каждого свой путь; всё пишется только внутри него и `.claude/worktrees/*`).

Эта памятка — указатель, а не второй экземпляр правил: раньше здесь была полная копия
протокола, и она разошлась с источниками (путь `D:\…`, «P2 — резерв», worktree на задачу,
ручной merge в корне). Правила живут в одном месте:

| Что | Где |
|---|---|
| Кто такой P1, границы роли (не чинит баги → P3, не делает CSS → P4, `// CSS:`-передача) | [`docs/dev-roles.md`](../dev-roles.md) §Developer roles, §CSS ownership |
| Очередь | `STATUS-P1.md` — строки `ROADMAP.md:NN`, строго сверху вниз; бриф — `docs/tasks/<id>.md` |
| Старт, слот пула, ветка `p1-…`, merge+push после каждого коммита | [`CLAUDE.md`](../../CLAUDE.md) §Session start and git · [`docs/git-workflow.md`](../git-workflow.md) |
| Правила кода и гейт | [`docs/conventions.md`](../conventions.md) · [`docs/commands.md`](../commands.md) |
| Какие документы обновить | [`docs/doc-sync.md`](../doc-sync.md) |
| Завершение задачи | скилл `/lumen-task-finish` |
| Нашёл баг по ходу | строка `OPEN` в `BUGS.md` со следующим `BUG-NNN`, продолжай свою задачу |
