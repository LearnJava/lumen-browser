# Исследования (docs/research)

Внешние исследования, на которых стоят решения и задачи. Каждое исследование — отчёт плюс
приложения по областям; факты в приложениях проверены по источникам отдельным проходом
(подтверждено / исправлено в деталях / «(не проверено)»). Состояние кода Lumen, упомянутое в
отчётах, снято на конкретном коммите и **устаревает** — перед заведением задачи сверяйся с main.

## Как устроено каждое исследование

- `report.md` — сводный отчёт: выводы, приоритеты, требования. Читать первым.
- `areas/NN-*.md` — приложения по областям: находки с механизмом, тем, как это решают другие
  браузеры, рекомендацией и 1–3 источниками. Сюда — за деталями и ссылками.
- `review-notes.md` — правки рецензента и **остаточные замечания**, которые не исправлены
  (противоречия между приложениями, непроверенные детали).
- `site-compat/strategies/` — три независимые стратегии (пользователь / инженерный процесс /
  рынок), из которых собран раздел 7 отчёта о совместимости.

## Ограничения (общие для обоих)

- Массовость оценена косвенно: голоса и дубли в баг-трекерах, установки обходных расширений,
  UseCounter Chrome. Это голос активного меньшинства.
- Лимит веб-поиска в обоих прогонах исчерпывался; дальше использовались первоисточники
  (Bugzilla REST, GitHub, исходники Chromium/Firefox/WebKit). Reddit, Habr и форумы банков
  охвачены слабо.
- Числа без ссылки на источник помечены как рекомендация исследования — их калибруют замером.
