# TOUCH-1-S4 — чистый трекер касаний в shell

Срез 4 из TOUCH-1. Владелец — P1. Крейт — `lumen-shell`, новый модуль без подключения к окну.

## Цель

Модуль `crates/shell/src/touch_state.rs` с `TouchTracker` без зависимостей от `Lumen` и окна, по образцу `momentum_anim.rs`.

`on_touch(id: u64, phase: TouchPhase, pos: (f32, f32)) -> Vec<TouchOut>`:

- ведёт активные касания;
- первичный указатель — первое касание без других активных;
- выдаёт `pointerId`: `1` занят мышью, касаниям даются `2, 3, …` без повторного использования, пока касание активно;
- возвращает выходы `Down` / `Move` / `Up` / `Cancel` с `pointer_id`, `is_primary`, позицией;
- для двух и более пальцев считает центроид и расстояние между двумя первыми касаниями (на будущее для pan/pinch).

`Moved` для неизвестного id и повторный `Started` с тем же id обрабатываются без паники: первое игнорируется, второе даёт `Cancel` старого и `Down` нового.

`TouchPhase` — из `winit::event`, он строится в тестах без дисплея.

## Готово, когда

Юнит-тесты в модуле на синтетических последовательностях:

- одиночный тап;
- два пальца с пересекающимися фазами;
- `Cancelled`;
- неизвестный id;
- повторный `Started`;
- центроид и расстояние для двух пальцев;
- `pointerId` не переиспользуется, пока касание активно.
