# TEXTQ-2 — гамма и контраст покрытия глифа

Дорожка TEXTQ, срез 2. Владелец — P1. Крейт — `lumen-paint`. **Зависит от:** TEXTQ-1 (страница качества текста и привязка к пикселям уже есть).

## Зачем

Покрытие глифа идёт в альфу как есть: `alpha = textureSample(atlas).r` ([shaders.rs:558](../../crates/engine/paint/src/renderer/shaders.rs#L558), `TEXT`-шейдер), смешивание — обычный `ALPHA_BLENDING` в gamma-кодированном пространстве (поверхность намеренно не-sRGB, [diagnostics.rs:34](../../crates/engine/paint/src/renderer/diagnostics.rs#L34)). Ни гаммы, ни усиления контраста, как у DirectWrite/Skia, нет. Результат: тёмный текст на светлом выглядит тоньше и бледнее, чем в Chrome, светлый на тёмном — наоборот, «жирнеет».

## Что сделать

1. Одна функция коррекции покрытия `corrected = f(coverage, luminance(text_color))` в стиле Skia/WebRender (gamma LUT + contrast):
   - luminance — по коэффициентам Rec. 709 от цвета текста;
   - для тёмного текста покрытие поднимается (контраст + гамма < 1 по покрытию), для светлого — компенсируется в обратную сторону;
   - параметры (`gamma`, `contrast`) — константы в одном месте с doc-комментарием. Ориентир для старта — значения DirectWrite по умолчанию (gamma 1.8, grayscale enhanced contrast 1.0); подобрать по странице качества текста из TEXTQ-1 так, чтобы толщина штрихов на 12–16 px визуально совпала с Edge. Выбранные числа и diff% «до/после» записать в ROADMAP-строку.
2. GPU: применить в `fs_main` текстового шейдера. Цвет текста уже приходит в вершине (`in.color`) — достаточно вычислить в шейдере; если быстрее — LUT 256×N в маленькой текстуре.
3. CPU (`cpu_raster.rs`, место композиции покрытия глифа рядом с растеризацией текста, `~:3350`): та же функция, общий модуль для обоих путей (две независимые реализации каждого `DisplayCommand` — [crates/engine/paint/CLAUDE.md](../../crates/engine/paint/CLAUDE.md); коррекция обязана совпадать). CPU-эталоны сдвинутся — перегенерировать.
4. Флаг отключения для сравнения: переменная окружения `LUMEN_TEXT_GAMMA=0` (описать в [docs/automation.md](../automation.md) §Flags или там, где перечислены env-переменные paint).

## Не трогать

- Субпиксельный (ClearType/LCD) антиалиасинг — вне задачи.
- Растеризатор `lumen-font`.

## Готово, когда

1. Юнит-тест функции коррекции: монотонна по покрытию, `f(0)=0`, `f(1)=1`, для чёрного текста `f(0.5) > 0.5`.
2. Страница качества текста снята до/после в обоих путях, числа в ROADMAP-строке.
3. Полный `python graphic_tests/run.py --continue-on-fail`, CPU-PNG (`graphic_tests/snapshots/cpu/`) и затронутые эталоны перегенерированы в том же коммите.
4. `cargo clippy -p lumen-paint --all-targets -- -D warnings` чисто.
