# CSSANIM-MODEL-2 — срезы
Срез 1 CSSANIM-MODEL (a4783c55e, 2026-10-22) сделал настоящие `CSSAnimation`/`CSSTransition` в JS-шиме (`_css_*`, `web_api_shim_tail_b.js:7160+`) с собственными часами `_c`, наложением значения на `getComputedStyle()` (BUG-1293) и `getAnimations()`; WPT-подмножество (24 файла, 146 подтестов) 43 → 111. Рисует кадр и шлёт события по-прежнему Rust: `AnimationScheduler` (`crates/shell/src/animation_scheduler.rs`, `opacity`/`transform`/цвета/`height`) и `TransitionScheduler` (`crates/engine/layout/src/animation.rs:1535`), события приходят через `deliver_animation_events` (`crates/shell/src/lumen/animation_events.rs`) в `_lumen_deliver_animation_events` (`web_api_shim_mid_b4.js:813`).

Остаток разбит по пунктам исходной строки: п. 3 (события от перемотки) — S1, п. 2 (замена эффекта, composite) — S2, п. 1 (стиль до изменения) — S3, п. 4 (нарисованный кадр) — S4/S5, часть п. 5 («ancestor» `display: none`) — S6. Порядок такой, чтобы S2 использовал события S1. Точные числа PASS по подтестам заранее не сняты (прогон WPT в сессии планирования не стартовал: хост `web-platform.test` не резолвился), поэтому критерии даны по файлам из ROADMAP; перед началом каждого среза исполнитель снимает базу по файлу (`python tests/wpt/run_smoke.py --binary target/dev-release/lumen.exe <id>` с пустой metadata, рецепт — в памяти проекта `project_cssanim_model_slice1_2026_10_22`) и записывает числа в коммит. Тесты JS — `crates/js/src/dom/tests/v8_cssanim_model.rs` (шаблон: подмена `_lumen_computed_property`, `performance.now`, `__sync()`).

Вне срезов (оставить в ROADMAP остатком CSSANIM-MODEL-3): `::marker` и `::before`/`::after` у переходов, анимации на `::before`/`::after` без `content` без вычисленного стиля от слоя, pseudo-тесты `Element-getAnimations` — формулировка размыта, нужна отдельная разведка по списку падающих подтестов.
