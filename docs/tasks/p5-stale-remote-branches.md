# Невлитые ветки в `origin` — закрыто 2026-08-31

Записка оставлена ради одной практической вещи — **SHA удалённых веток**, по которым любую из
них можно вернуть. Разбор каждой лежит в истории коммита `b7d73bf9e`.

`origin` держал 31 ветку; влитые удалены механически, четыре оставшиеся разобраны по
содержимому и удалены по решению пользователя. Осталось две ссылки: `main` и постоянный
полигон `p1-exp-wgpu-only`.

## Что удалено и как вернуть

```bash
git push origin <sha>:refs/heads/<имя>
```

| Ветка | SHA на момент удаления | Почему удалена |
|---|---|---|
| `p1-p3-bfcache` | `decda3173d318e9d1b59e467fb7787fdbcc9854e` | Содержимое целиком в `main`: `BfCachePayload`, `FrozenPage`, `has_frozen()` и тестовые хелперы пришли другим путём |
| `merge-bug085-temp` | `6721d00c0364758afa7cf6aed47fadef39ca61e0` | [BUG-085](../../BUGS-FIXED.md) закрыт в `main` на три недели позже и иначе. Ветка держала в `origin` бинарник `utils/lumen.exe` 26.9 МБ и огрызки `last_session.db-*` |

`p1-exp-wgpu-only` (`03b8599d733061c02c7ffa031448800b6d9b0e5c` на ту же дату) **не удалялся** —
постоянный экспериментальный полигон, в `main` не вливается по замыслу, статус ведётся в
`EXPERIMENT.md` на самой ветке.

## Два правила для следующей чистки

**Старую ветку нельзя вливать `git merge`.** Все четыре предшествовали перестройкам
репозитория: слияние `p1-wgpu-cross-platform` удалило бы `.claude-manager/` и воскресило
`.claude/memory/*` — раскладку, которой больше нет. Если из восстановленной ветки что-то
нужно, брать точечно:

```bash
git diff main...<ветка> -- <путь> | git apply --3way
```

**Проверять содержимое, а не название.** «В ветке есть коммиты, которых нет в `main`» ничего
не говорит о том, есть ли в `main` их содержимое. `merge-tmp-bug591-sw` выглядела застрявшей
чужой работой, а оказалась merge-коммитом, оба родителя которого уже в `main`. И наоборот:
`merge-p2-bug076` по названию читалась как доводка закрытого бага, а несла отдельную
оптимизацию offscreen-слоя — которая тоже успела прийти в `main` своим путём, но узнать это
можно было только прочитав диф.
