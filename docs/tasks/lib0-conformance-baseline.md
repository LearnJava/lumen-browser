# LIB-0 — Перепись конформности «до» (URL, текст, SVG)

**Developer:** P1 · **Branch:** `p1-lib0-conformance-baseline` · **Size:** S · **Crates:** `lumen-core` (чтение), `lumen-font` (чтение), `lumen-layout`/`lumen-paint` (чтение) — правок кода движка задача НЕ содержит
**Roadmap:** LIB-0 (под `LIB` «Готовое вместо своего», [ADR-027](../decisions/ADR-027-own-vs-vendored-boundary.md))
**Метод:** [`docs/conformance-method.md`](../conformance-method.md)

---

## Статус

**READY.** Первая задача дорожки. Ничего не меняет в движке — только измеряет.

## Зачем именно первой

Три последующие задачи заменяют свой код на внешние крейты. Без числа «до»:

- нечем доказать, что замена улучшила результат (ADR-027 требует роста цифры,
  иначе замена откатывается);
- решение по URL (`LIB-6`) принимать не на чем — оно сформулировано как «по
  цифре», а не «заменить»;
- нельзя отличить сдвиг эталона, вызванный сменой шейпера, от настоящего
  регресса.

## Что сейчас

Три подсистемы, измеренные чтением кода 2026-08-31 (числа — в ADR-027):

- **Шейпинг** — `crates/engine/font/{shape,gsub,gpos,otlayout}.rs`, ~1350 строк.
  GSUB реализует lookup-типы 1 и 4 из 8, GPOS — 1 и 2 из 9. Нет GPOS 4
  (mark-to-base), то есть комбинирующая диакритика не прикрепляется к базе.
- **SVG** — `crates/engine/layout/src/box_tree/svg.rs` +
  `crates/engine/paint/src/svg_path.rs`. Ноль вхождений `linearGradient`,
  `radialGradient`, `url(#`. Нет `clipPath`, `mask`, `filter`, `pattern`,
  `marker`, вложенного `<image>`.
- **URL** — `crates/core/src/url.rs`, ~370 строк реализации (остальное тесты).
  Нет конечного автомата WHATWG и наборов процент-энкодинга.

Ни одна из трёх цифр не измерена против эталона — все три получены чтением.

## Что сделать

1. **URL.** Скрипт (Python или тест `lumen-core`), прогоняющий
   `Url::parse`/`Url::resolve` по `tests/wpt/url/resources/urltestdata.json`.
   Записи, относящиеся к API-сеттерам (`href =`, `protocol =`, …), из
   знаменателя исключить — таких свойств у нас нет; исключение зафиксировать
   явным списком, а не молчаливым пропуском.
   Отчёт: пройдено/всего + **разбивка провалов по причинам** (процент-энкодинг,
   IDN, схемы без хоста, `..`-сегменты, пустой query). Без разбивки цифра не
   отвечает на вопрос `LIB-6` «заменять или чинить точечно».
2. **Текст.** Страница-проба с восемью независимыми проверками из
   `conformance-method.md` §3.2 (лигатура, кернинг, комбинирующая диакритика,
   вьетнамский, арабское соединение, деванагари, иврит, RTL) + контрольная
   строка, которая обязана отрисоваться при любом состоянии движка.
   Снять скриншот **и** `--dump-display-list`; основное свидетельство — дамп.
3. **SVG.** Страница-проба из `conformance-method.md` §3.3, прогнать **дважды**:
   inline в разметке и внешним файлом через `<img src=*.svg>` — это два разных
   пути движка (второй идёт через `lumen_image::is_svg` +
   `crates/shell/src/svg_image.rs`), и заменяются они разными задачами
   (`LIB-5` и `LIB-4` соответственно).
4. Записать результат в `docs/conformance/<ГГГГ-ММ-ДД>.md`: знаменатель,
   пройдено, доля, разбивка, `git rev-parse --short HEAD`, машина и ОС.

## Тонкости

- **Знаменатель фиксируется здесь и не меняется потом.** Если после замены
  захочется «уточнить» набор проверок — цифры перестанут быть сравнимыми.
  Уточнение допустимо только как *дополнительный* набор рядом со старым.
- **Скриншоты Windows и Linux несравнимы** — эталоны `dump-golden/` сняты на
  Windows, на Linux шесть из двенадцати проверок расходятся на неизменённом
  `main` из-за метрик шрифта. Записать в отчёт, на какой машине снято.
- **Проба не должна называть то, что сама определяет** — страница для градиента
  не должна использовать `clipPath`, иначе один провал скроет другой.
- Файл `docs/conformance/<дата>.md` для состояния «до» **не переписывается
  никогда**: он база для всех последующих сравнений.

## Валидация

Задача закрыта, когда в `docs/conformance/` лежит файл с тремя таблицами, в
каждой назван знаменатель, и по нему можно принять решение `LIB-6`. Никаких
изменений в `crates/` быть не должно — `git diff --stat crates/` пуст.
