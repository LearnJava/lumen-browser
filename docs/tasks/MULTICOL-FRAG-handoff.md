## Как устроено сейчас (прочитано)
- `box_tree/multicol_abspos.rs::build_multicol_init` делит детей на сегменты по `column-span: all`, решает `sliceable` (`box_is_column_sliceable` — только лист-блок без детей/рамок или цепочка прозрачных обёрток) и `grid_frag`.
- `box_tree/multicol_trampoline.rs`: Measure (каждый item раскладывается в колонку шириной `col_w`, высоты — `frame.outer_hs` = mt+h+mb) → `finish_measure_phase`: `emit_grid_fragments` | `emit_sliced_fragments` (виртуальный стек + `cut_chain` режет лист окном `[col_lo,col_hi)`) | атомарная ветка (`compute_col_assignment` + `Phase::Place`, `pack`/`balanced_height` из `multicol_fragmentation.rs`, целые боксы).
- Строки `InlineRun`: однородные, `line_h = rect.height / lines.len()`, paint рисует строку `i` в `rect.y + i*line_h` (`paint/display_list/text_run.rs::emit_inline_run`) — срез = `lines[a..b]` + новые `rect.y/height`.
- `multicol_span::trim_edge(piece, top)` обнуляет margin/padding/border одной кромки (slice). `shapes_floats::shift_tree(b, dx, dy)` сдвигает поддерево. `multicol_break::breaks_before/after` — принудительные разрывы; `multicol_fragmentation::item_lines` → `Lines(n)/Glue/Other`, `forced_breaks(items)`.
- У `LayoutBox` есть `Drop`, поэтому «клон без детей» = структурный литерал со всеми полями (node, rect, style, used_line_height, used_padding, grid_baselines, fieldset_legend, table_caption_inset, clamp_clip, subgrid_tracks, kind, children, col_span, row_span, svg_group_transform, scroll_x, scroll_y, dirty, origin).

## План (спроектирован, не написан)
Новый модуль `box_tree/multicol_flow.rs` (подключить `mod` в `box_tree.rs` рядом с `multicol_break`), заменяет внутренности `emit_sliced_fragments`; все сегменты multicol с `n_cols>1 || col_rows`, горизонтальные, кроме `forced_rows_wanted`/`grid_frag`, идут туда (старый `box_is_column_sliceable` убрать, если станет мёртвым; атомарная ветка остаётся для `forced_rows_wanted`/вертикальных).

1. **Модель разрывов** (`FlowModel`) в «виртуальных» y (стек items: `top_i = v + mt_i`, `v += mt+h+mb`, как сейчас без прыжков `stack_with_breaks`): список кандидатов `Cand{end, resume, forced, avoid, lines_violation}` + непересекающиеся интервалы `hard` (монолит: замещаемые/не-Block kind, `overflow`≠visible/clip, `contain` size|layout|paint, transform/filter/clip-path/mask, float, display ≠ block/list-item/flow-root, вложенный multicol, `fieldset_legend`, `svg_group_transform`, глубина > 48), `soft` (`break-inside: avoid`), `free` (листья и «хвост» блока после последнего ребёнка: разрез в любой точке). Кандидаты: зазоры между соседями на любой глубине (`end` = низ предыдущего, `resume` = верх следующего; для принудительного на уровне items `resume = top − margin_top`), между строками `InlineRun` (`end=resume`), учёт `orphans/widows` по прогону строк (прогоны соединяются через `Glue`; нарушение: `j<orphans || L−j<widows`), `avoid` от `break-before/after: avoid`. `Glue` и float из зазоров исключать.
2. **Пагинация** `paginate(heights, strict)`: окно `[lo,hi)`; если остаток помещается — последнее; иначе ближайший принудительный `end∈(lo,lo+h]`; иначе лучший кандидат по (ярус asc, end desc): ярус 0 чистый, 1 нарушает orphans/widows, 2 нарушает avoid; точка `lo+h` внутри `free` — тоже кандидат; нет подходящего — переполнение: первый кандидат с `end>lo+h` вне `hard`. `strict` (для баланса): любой ярус ≥1 или переполнение → `None`.
3. **Баланс**: бинарный поиск минимального `h∈[ceil(end/n), min(end,limit)]` со `strict`-пагинацией, цель — `max(n, окон при h=∞)`; не нашлось — `limit` без strict. `column-fill: auto` без лимита — `h=∞`. Режим рядов (`ColRows`) — высоты `first_h` для первых `n` окон, затем `later_h`, как в нынешнем `emit_sliced_fragments`.
4. **Нарезка** `cut(src, top, lo, hi, last, dx, dyv, depth)`: целиком внутри окна → `clone` + `shift_tree(dx, top+dyv−src.rect.y)`; монолит — целиком в окно, где его `top`; фрагментируемый Block на границе → оболочка (`shell`), `rect` = пересечение, `trim_edge` сверху при `top<lo` и снизу при `bottom>hi` (+ обнулить радиусы углов `border_*_radius{,_y}` на срезанной кромке), дети рекурсивно, abspos/Skip-дети — только в первый фрагмент; `InlineRun` — срез `lines[a..b]`, `a=ceil((lo−top)/lh−0.01)`, `b=ceil((hi−top)/lh−0.01)`, `rect.y=top+a*lh+dyv`, `height=(b−a)*lh`. У item-фрагмента `rect.width = col_w`.

Тесты: `box_tree/tests/multicol_flow.rs` (подключить в `tests/mod.rs`); существующие `multicol_*` тесты (особенно `multicol_orphans`, `multicol_forced_break`, `multicol_mixed_break`, `multicol_break_inside`, `multicol_rows`) должны остаться зелёными либо быть осознанно обновлены, если кодировали «текст в одну колонку».
