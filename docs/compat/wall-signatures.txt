# Сигнатуры «стен» для проверки 2 краулера паритета (scripts/compat_crawl.py, COMPAT-CORPUS-1).
# Стена — страница-заслонка вместо контента: проверка браузера, WAF-отказ, «браузер не
# поддерживается», «включите JavaScript». Проверка 2 падает, если на странице Lumen найдена
# стена, которой нет у Chrome на том же сайте (сравниваются множества `класс:id`).
#
# Формат: <класс> <TAB> <id> <TAB> <регулярное выражение (регистр не важен, Python re)>
# Классы: challenge (проверка браузера/антибот), captcha, waf (отказ в доступе),
#         unsupported (браузер не поддерживается/устарел), nojs (нужен JavaScript), geo.
# Это временное место: целевой дом сигнатур — пакет совместимости (report.md §7.6 п.3, п.4);
# классификатор поломок один на страницы ошибок, панель сайта и краулер.
# Строки с # — комментарии; пустые игнорируются; id уникален в пределах файла.
