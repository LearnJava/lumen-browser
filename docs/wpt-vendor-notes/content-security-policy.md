# WPT vendor notes — `content-security-policy`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-25 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-content-security-policy`, `docs/wpt-status.md`), in-scope (⬜, Content Security Policy — already partially implemented in Lumen: directive/source-list parsing in `crates/network/src/csp.rs`, persisted report-only policies in `crates/storage/src/csp_policies.rs`). Same pinned commit, `git sparse-checkout` at the same commit hash, 1356 files — by far the largest category vendored so far, 44 subdirectories (`base-uri`, `blob`, `child-src`, `connect-src`, `default-src`, `embedded-enforcement`, `font-src`, `form-action`, `frame-ancestors`, `frame-src`, `gen`, `generic`, `img-src`, `inheritance`, `inside-worker`, `media-src`, `meta`, `navigation`, `nonce-hiding`, `object-src`, `parsing`, `plugin-types`, `report-hash`, `reporting`, `reporting-api`, `resource-hints`, `resources`, `sandbox`, `script-src`, `script-src-attr-elem`, `securitypolicyviolation`, `style-src`, `style-src-attr-elem`, `support`, `svg`, `unsafe-eval`, `unsafe-hashes`, `wasm-unsafe-eval`, `webrtc`, `worker-src`, `xslt`) plus root `META.yml`/`WEB_FEATURES.yml`/`README.html`/`README.css`/`spec.src.json`. Out-of-category helpers not vendored: `/common/utils.js`, `/common/security-features/resources/common.sub.js`, `/common/redirect.py`, `/common/subset-tests.js`, `/common/dispatcher/dispatcher.js`, `/common/media.js`, `/media/*`, `/service-workers/service-worker/resources/test-helpers.sub.js`, `/resources/testdriver.js`+`testdriver-vendor.js`, `/fonts/Ahem.ttf`, same documented survey gap as `FileAPI`/`clipboard-apis`. Also the largest by selected-id count: `run_report.py --all --root content-security-policy --recursive` selects 865 ids across the ~40 subdirectories — did not complete (same limitation class as `bluetooth`/`client-hints`, a full run at this pace would take hours); a bounded ~10:25 trial run (stopped manually) processed 67 ids: 13 harness OK, 18 "Test TIMEOUT" (harness ran, partial subtests recorded, overall timed out), 32 bare TIMEOUT (harness never reported at all), 3 ERROR (session/URL-reuse artifact, same class as `accelerometer`/`beacon`/`clipboard-apis`), 1 SKIP (`Executor does not support testdriver.js`). 2/185 subtests passed among the tests with subtest data. Failure clusters in the trial: most FAILs are the same out-of-category-helper 404 gap (`ReferenceError: log is not defined` from the un-vendored `/common/security-features/resources/common.sub.js`, plus `alertAssert.sub.js`/`logTest.sub.js` 404s); a few (`base-uri-allow*`/`base-uri-deny*`) expect the CSP-restricted navigation's resulting URL but got `undefined` — the existing `crates/network/src/csp.rs` parser exists but its `base-uri` directive doesn't appear wired into navigation, a genuine gap in the partial implementation; dynamic `import()` under CSP (`connect-src-*-import-blocked`) fails with `Error: Not supported` — dynamic `import()` itself appears unimplemented in the JS engine, a broader gap than CSP alone. Not filed as a separate BUG-NNN — first pass only vendors + runs a bounded trial. See `docs/wpt-status.md` for details.
