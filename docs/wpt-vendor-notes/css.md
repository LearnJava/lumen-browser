# WPT vendor notes — `css`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-26 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-css`, `docs/wpt-status.md`), in-scope (⬜, the umbrella top-level directory for every CSS spec test suite — `CSS1`/`CSS2`, `WOFF2`, `compositing`, and every `css-*` module: `css-align`, `css-anchor-position`, `css-animations`, `css-backgrounds`, `css-box`, `css-break`, `css-cascade`, `css-color`, `css-conditional`, `css-contain`, `css-display`, `css-flexbox`, `css-fonts`, `css-grid`, `css-transforms`, `css-transitions`, … — already Lumen's largest single implementation surface, `css-parser`+`layout`+`paint`). Same pinned commit, `git sparse-checkout` at the same commit hash. By far the largest category vendored so far: 54350 files, ~209 MB (vs. the previous largest, `content-security-policy`'s 1356 files) — a `git sparse-checkout` of the single upstream `css/` root directory, copied verbatim, no filtering. Out-of-category helpers are not individually enumerated here (impractical at this scale, unlike smaller categories) — the bounded trial run below observed 404s on `/resources/check-layout-th.js` (56 hits) and `/fonts/ahem.css` (3 hits), same un-vendored-helper survey gap as `compat`'s `webkit-box-item-shrink-001/002`; the full un-vendored-dependency surface across all 34607 selected ids is unknown. The manifest selects **34607 ids** — also by far the largest (next: `content-security-policy`'s 865) — so `run_report.py --all --root css --recursive` did **not** complete, same limitation class as `bluetooth`/`client-hints`/`content-security-policy` but far more extreme (at the observed pace, a full run would take on the order of a day, not hours). A bounded ~11:30 trial run (stopped manually) processed 382 of 34607 ids (~1.1%, covering `CSS1`/`CSS2` box-model/floats/normal-flow tests plus the start of `compositing`): 267 SKIP (`Executor does not support testdriver.js`, same gap as `accname`/`clear-site-data`), 62 bare TIMEOUT (harness never reported), 53 harness OK with 1294/2594 subtests passed. Failure clusters in the trial: `background-blend-mode` not recognized in computed style (38 occurrences — the property isn't implemented); `document.elementFromPoint is not a function` (32 occurrences — missing DOM API); several `min-height:stretch`/`calc()` margin-collapse-through cases FAIL (`assert_equals: margins should collapse through expected 50 but got 0`); the `webkit-box-item-shrink`-style layout tests 404 on the un-vendored `/resources/check-layout-th.js`+`/fonts/ahem.css`, same gap as `compat`. Not filed as a separate BUG-NNN — first pass, bounded trial only, failures are a mix of already-known missing-feature classes rather than a single fresh regression. See `docs/wpt-status.md` for details.

### Инструмент: что изменилось в `reftest_pixdiff.py`
