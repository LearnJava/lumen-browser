# WPT vendor notes — `editing`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-27 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-editing`, `docs/wpt-status.md`), in-scope (⬜, legacy editing — `document.execCommand`/`contenteditable`/`designMode` — plus the modern EditContext API). Same pinned commit, `git sparse-checkout` at the same commit hash, 379 files (`crashtests/` 144, `other/` 97, `run/` 43, `data/` 36, `whitespaces/` 19, `plaintext-only/` 13, `manual/` 9, `edit-context/` 9, `include/` 6, plus `META.yml`/`README`/`event.html`). Out-of-category helpers **not** vendored — `/resources/testdriver.js`+`testdriver-vendor.js`+`testdriver-actions.js`, `/common/subset-tests.js`, `/img/lion.svg` — same documented survey gap as `FileAPI`/`ai`. `run_report.py --all --root editing --recursive` selected 700 ids and completed in ~34 min: 86/700 harness OK, 14/2310 subtests passed, 429 SKIP (`Executor does not support testdriver.js` — 61% of the category, since editing inherently needs synthesized input), 183 TIMEOUT, 2 ERROR. Two dominant engine causes: BUG-346 (unresolved `..` dot-segments — 614 of 723 HTTP 404s are the category's *own* vendored `include/`/`data/` files requested through `..`, which is why the entire generated `run/` conformance set never loaded its test engine) and the new BUG-353 (`element.focus()`/`blur()`/`document.activeElement` missing from the shim — 371 subtest failures across 12 files). See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-27 (коммит `35be3b44`, `tests/wpt/editing/`, 379 файлов: `META.yml`, `README`, `crashtests/` — 144, `other/` — 97, `run/` — 43, `data/` — 36, `whitespaces/` — 19, `plaintext-only/` — 13, `manual/` — 9, `edit-context/` — 9, `include/` — 6, `event.html`), в скоупе ⬜ (`document.execCommand`/`contenteditable`/`designMode` — legacy-editing, плюс современный EditContext API). Внекатегорийные хелперы `/resources/testdriver.js`+`testdriver-vendor.js`+`testdriver-actions.js` (89/88/84 ссылки), `/common/subset-tests.js` (109 ссылок), `/img/lion.svg` (2) не довендорены — та же методология, что `FileAPI`/`ai`. Прогон `run_report.py --all --root editing --recursive` добежал целиком за ~34 мин: 700 id (321 файл, `run/*.html` и часть `other/` раскрываются в `?N-M`-варианты), **86/700 harness OK, 14/2310 сабтестов passed**, 429 SKIP, 183 TIMEOUT, 2 ERROR. Разбивка причин: (1) **429 SKIP** — `Executor does not support testdriver.js` (тот же гэп, что `accname`/`attribution-reporting`; здесь он съедает 61% категории, потому что редактирование по природе требует синтетического ввода); (2) **[BUG-346](../bugs/BUG-346-OPEN.md)** (dot-segments не схлопываются в `Url::resolve`) — крупнейшее независимое подтверждение бага: 614 из 723 HTTP-404 приходятся на вендоренные же файлы, запрошенные через `..` — `/editing/run/../include/tests.js`+`implementation.js`+`reset.css` (по 109), `/editing/other/../include/editor-test-utils.js` (80), `/editing/plaintext-only/../include/editor-test-utils.js` (22), `/editing/run/../data/*.js` (~76). Отсюда же вся масса `EditorTestUtils is not defined` (8324 упоминания) и `browserTests is not defined` (109) — то есть почти весь `run/`-конформанс-набор (главный, генерируемый набор категории) не отработал ни одной содержательной проверки: он даже не загрузил свой движок тестов; (3) **[BUG-353](../bugs/BUG-353-OPEN.md)** — новый: `element.focus()`/`blur()` и `document.activeElement` отсутствуют в шиме целиком (371 сабтест в 12 файлах: `editor.focus is not a function` ×334, `editingHost.focus` ×24, `div.focus` ×9, `editable.focus` ×4); (4) `EditContext is not defined` (40) — EditContext API не реализован вовсе, ожидаемо; (5) `xmldoc.execCommand is not a function` (2) — `execCommand` есть на живом `document`, но не на XML-документе из `DOMImplementation` (мелкий довесок к тому же классу, отдельным багом не заводился). Содержательно прошли только 8 файлов с ненулевым числом сабтестов, из них полностью один — `other/removeformat_background_color.html` (6/6); ещё `other/selectall-without-focus.html` 2/3, остальные по 1 сабтесту. Заведён [BUG-353](../bugs/BUG-353-OPEN.md); остальные кластеры — либо уже заведённый BUG-346, либо известные гэпы исполнителя, либо ожидаемая нереализованность самой спеки редактирования (⬜)
