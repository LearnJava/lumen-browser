# WPT vendor notes — `shadow-dom`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-06 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-shadow-dom`, `docs/wpt-status.md`), scope ⬜ (candidate). Same pinned commit, `git sparse-checkout add` at the same commit hash, `LICENSE-WPT.md` copied from the sibling `selection` category, 393 files (`META.yml`, `WEB_FEATURES.yml`, root tests plus `crashtests/`, `declarative/`, `focus/`, `focus-navigation/`, `leaktests/`, `reference/`, `reference-target/`, `resources/`, `untriaged/`). No `.https.` files, no `variant` hits, 97/392 files pull `testdriver.js`. `run_report.py --all --root shadow-dom --recursive --processes=4` completed in ~4:07 (276 selected ids): **198/276 harness OK, 221/1780 subtests** — Shadow DOM is substantially implemented end-to-end, a sharp contrast with the mostly-empty runs typical of this backlog. Dominant failure classes are all reconfirmations of already-open bugs — [BUG-384](../../bugs/BUG-384-FIXED.md) (named access on `window` missing, the largest cluster — bare `container`/`host`/`sandbox`/`test1`..`test6` identifiers), [BUG-346](../../bugs/BUG-346-OPEN.md) (`..` dot-segments not collapsed by `Url::resolve()` — `../../../../html/resources/common.js` 404s, `newHTMLDocument is not defined`), [BUG-574](../../bugs/BUG-574-OPEN.md) (`Node.contains` missing, 52 hits), [BUG-415](../../bugs/BUG-415-OPEN.md) (detached `createHTMLDocument()` document lacks Node methods — surfaces here as `document.createNodeIterator`/`importNode is not a function` on the detached doc), [BUG-464](../../bugs/BUG-464-OPEN.md)/[BUG-477](../../bugs/BUG-477-OPEN.md) (`document.elementFromPoint`/`elementsFromPoint` missing), [BUG-601](../../bugs/BUG-601-OPEN.md) (global `DOMTokenList` constructor missing), [BUG-471](../../bugs/BUG-471-OPEN.md) (CSSOM not wired up). A live probe (`--mcp-live-port`, independent of the WPT runner) confirmed one new, previously unfiled defect — [BUG-676](../../bugs/BUG-676-OPEN.md): `ShadowRoot` is a plain `{}`-literal, not a `class`/prototype-chained WebIDL interface — no global `window.ShadowRoot` constructor at all (`'ShadowRoot' in window === false`), `instanceof` throws instead of testing, `cloneNode()` is missing entirely (spec requires it to throw `NotSupportedError`, not be absent) — same defect class as [BUG-671](../../bugs/BUG-671-OPEN.md) (`Selection`)/[BUG-369](../../bugs/BUG-369-FIXED.md)/[BUG-370](../../bugs/BUG-370-FIXED.md) (`Headers`/`Response`); a companion gap on a sibling object, `HTMLSlotElement.prototype.assign()` (imperative slot API), is missing entirely next to working `assignedNodes`/`assignedElements`. See `docs/wpt-status.md` for the full breakdown.
