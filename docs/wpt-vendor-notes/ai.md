# WPT vendor notes — `ai`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-23 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-ai`, `docs/wpt-status.md`), included despite its 🚫 scope note (AI/Writer API, no LLM integration) by the same standing user decision as `accelerometer`/`acid`. Same pinned commit, `git sparse-checkout` at the same commit hash, 180 files (`classifier/`, `language-model/`, `language_detection/`, `proofreader/`, `rewriter/`, `semantic_embedder/`, `summarizer/`, `translator/`, `writer/`). One out-of-category helper (`/common/get-host-info.sub.js`) not vendored, same documented survey gap as `FileAPI`. The whole category is `.https.`-only (163 `*.window.js` + 6 direct `.html`, 0 non-https tests) — worse than `WebCryptoAPI`'s 122/125, the first category with zero isolatable test files; same HTTPS-port gap, but here a full `--all --root ai --recursive` run couldn't even be attempted to completion (10-minute trial run only reached a handful of ids, each TIMEOUT). See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-23 (`tests/wpt/ai/`, 180 файлов: `classifier/`, `language-model/`, `language_detection/`, `proofreader/`, `rewriter/`, `semantic_embedder/`, `summarizer/`, `translator/`, `writer/`), включена несмотря на скоуп 🚫 (AI/Writer API, нет LLM-интеграции) по тому же постоянному решению пользователя, что и `accelerometer`/`acid`. Внекатегорийный хелпер `/common/get-host-info.sub.js` не довендорен (та же методология, что `FileAPI`). Категория на 100% `.https.`-only (163 `*.window.js` + 6 прямых `.html`, 0 не-https тестов — впервые ни одного изолированно прогоняемого файла, хуже `WebCryptoAPI` 122/125).
