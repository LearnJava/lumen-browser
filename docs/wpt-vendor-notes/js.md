# WPT vendor notes — `js`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-05 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-js`, `docs/wpt-status.md`), scope ⬜ (candidate, core ECMAScript). Same pinned commit, `git sparse-checkout add` at the same commit hash, 32 files (`META.yml`, `LICENSE-WPT.md` copied from the sibling `is-input-pending` category, `behaviours/` — 3 files on private fields/`SetPrototypeOf` against `WindowProxy`, `builtins/` — 15 core-ECMAScript tests, `builtins/weakrefs/` — 11 `.optional.*` `FinalizationRegistry`/`WeakRef` tests). No `variant` hits, no `.https.` files, no `testdriver.js`. `run_report.py --all --root js --recursive` completed in ~38 s (26 selected ids): **25/26 harness OK, 110/130 subtests passed**. All 13 unexpected results trace to already-known causes, no new bug filed: `HostEnsureCanAddPrivateElement.window.html` TIMEOUT and `Promise-incumbent-global.sub.html` FAIL (`Cannot read properties of undefined (reading 'postMessage')`) both reduce to [BUG-480](../bugs/BUG-480-OPEN.md) (`<iframe>` has no separate browsing context — `iframe.onload` never fires, and `window.frames` is a self-reference stub, `frames === window` at `crates/js/src/dom.rs:13032`, so `frames[0]` is `undefined` instead of the child window); the 11 `builtins/weakrefs/*.optional.*` FAILs split between the unvendored out-of-category helper `/common/gc.js` (same documented-gap methodology as `FileAPI`/`IndexedDB`: `resources/maybe-garbage-collect.js` references the undefined global `garbageCollect` at load time, throwing before it can define `self.maybeGarbageCollectAsync`) and `FinalizationRegistry.prototype.cleanupSome`, a non-standard method from an early WeakRefs proposal draft removed before Stage 4 and unimplemented by every engine including V8 (hence the `.optional.` filename suffix). See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/js/`, 32 файла: `META.yml`, `LICENSE-WPT.md` скопирован из соседней `is-input-pending`, `behaviours/` — 3 файла про приватные поля/`SetPrototypeOf` на `WindowProxy`, `builtins/` — 15 тестов ядра ECMAScript (`Array`/`Math`/`Object.prototype`/`Promise`/`WeakMap`) + `builtins/weakrefs/` — 11 `.optional.*` тестов `FinalizationRegistry`/`WeakRef`), скоуп ⬜ (кандидат, ядро ECMAScript — прямое применение к любому JS-движку). `run_report.py --all --root js --recursive` — ~38 с, 26 отобранных id: **25/26 harness OK, 110/130 сабтестов**. Все 13 unexpected объясняются уже известным, новых багов нет: `HostEnsureCanAddPrivateElement.window.html` TIMEOUT и `Promise-incumbent-global.sub.html` FAIL (`Cannot read properties of undefined (reading 'postMessage')`) — оба по [BUG-480](../bugs/BUG-480-OPEN.md) (`<iframe>` без отдельного browsing context: `iframe.onload` не срабатывает, а `window.frames` — самоссылочная заглушка `frames === window`, `crates/js/src/dom.rs:13032`, поэтому `frames[0]` даёт `undefined`, а не реальное дочернее окно); 11 `builtins/weakrefs/*.optional.*` FAIL — частью на невендоренном внекатегорийном хелпере `/common/gc.js` (та же методология, что `FileAPI`/`IndexedDB`: `ReferenceError: maybeGarbageCollectAsync is not defined`, поскольку `resources/maybe-garbage-collect.js` при загрузке синхронно ссылается на неопределённый `garbageCollect` из невендоренного файла), частью на `FinalizationRegistry.prototype.cleanupSome` — нестандартном методе раннего черновика WeakRefs-предложения, удалённом из спеки до Stage 4 и не реализованном ни одним движком (включая V8, на который опирается Lumen), что и объясняет суффикс `.optional.` в именах файлов. Остаток (15/15 `builtins/`-тестов ядра ECMAScript кроме `Promise-incumbent-global`) — харнес OK, сабтесты все прошли: `Array.DefineOwnProperty`/`Array.prototype.join-order`/`Math.max`/`Math.min`/`Object.prototype.{freeze,getOwnPropertyNames,hasOwnProperty-order,hasOwnProperty-prototype-chain,preventExtensions,seal}`/`Promise-subclassing`/`WeakMap.prototype-properties`/`SetPrototypeOf-window` — все зелёные, что ожидаемо для V8-бэкенда.
