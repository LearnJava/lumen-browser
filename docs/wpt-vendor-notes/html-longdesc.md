# WPT vendor notes — `html-longdesc`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-04 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-html-longdesc`, `docs/wpt-status.md`). Same pinned commit, `git sparse-checkout` at the same commit hash. Category is 100% manual by spec design (all test files end in `-manual`, `run_report.py` selects 0/0 automatable ids). Sole signal came from a live `--mcp-live-port` probe: BUG-612 (`img.longdesc` has no IDL reflection, same class as BUG-602 `align`). **This row was missing when the category was landed (commit `ec14a7527`) and is reconstructed here from `ROADMAP.md`/`docs/wpt-status.md`, same gap class as the `hsts` row above.**

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-04 (коммит `35be3b44`, `tests/wpt/html-longdesc/`, 27 файлов: `META.yml`, `README.html`, `LICENSE-WPT.md`, 21 тестовый файл (все с суффиксом `-manual` — ручной AT-протокол, спека https://www.w3.org/TR/html-longdesc/, удалена из живого стандарта WHATWG HTML в 2013), 4 целевые страницы навигации (`pass(-fragment).html`/`fail(-fragment).html`), `rebased/fail.html`, `picture.png`), скоуп ⬜ (кандидат). Категория **на 100% ручная** — ни один файл, отбираемый `run_report.py` (glob исключает `-manual` по подстроке в имени, отобрал 6 id: `README.html`+4 целевые страницы+`rebased/fail.html`), не распознан `wptrunner`'ом как testharness-тест (`Unable to find any tests at the path(s)`) — это целевые страницы для ручной навигации, без `testharness.js`. `run_report.py --all --root html-longdesc --recursive` — **0/0**, автоматического сигнала нет. По правилу «пробуй даже без сигнала» — живая проба (`--mcp-live-port`, `<img longdesc="fail.html">`) вскрыла [BUG-612](../bugs/BUG-612-OPEN.md): `img.longdesc` — `undefined` (нет IDL-рефлексии, при рабочих `getAttribute`/`hasAttribute`), тот же класс, что уже заведённый [BUG-602](../bugs/BUG-602-OPEN.md) (`align`), но другое имя атрибута — не покрывается тем же баг-номером. Низкий приоритет: сама фича `longdesc` устарела и удалена из спеки.
