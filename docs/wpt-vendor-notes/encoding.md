# WPT vendor notes — `encoding`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-27 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-encoding`, `docs/wpt-status.md`), in-scope (⬜, Encoding Standard — `TextEncoder`/`TextDecoder`, `TextEncoderStream`/`TextDecoderStream`, and the legacy multi-byte decoder/encoder conformance suites). Same pinned commit, `git sparse-checkout` at the same commit hash, 341 files (`META.yml`, `WEB_FEATURES.yml`, 54 root-level tests/helpers, `resources/` — `encodings.js`, `ranges.js`, `single-byte-decoder.js`, `decode-common.js`, `decoding-helpers.js`, `encode-form-common.js`, `encode-href-common.js`, the `wptserve` handlers `single-byte-raw.py`/`text-html-meta-charset.py`/`text-plain-charset.py`, and the utf-32/BOM HTML+XML fixtures, `streams/` — 16 files, plus the four `legacy-mb-*` families: `japanese/` (euc-jp, iso-2022-jp, shift_jis), `korean/euc-kr`, `schinese/` (gb18030, gbk), `tchinese/big5`). Out-of-category helpers not vendored: `/common/subset-tests.js`, `/common/sab.js`, and `idlharness.any.js`'s `/resources/WebIDLParser.js`+`/resources/idlharness.js` — same documented survey gap as `FileAPI`/`ai`/`audio-session`. By far the longest run in this backlog so far: `run_report.py --all --root encoding --recursive` completed in **3 h 36 min** — 194 selected *files* expand into **1262 ids**, because 93 of them carry `<meta name="variant">` and fan out into 1193 `?N-M` subset variants. Result: **36/1262 harness OK, 146/2274 subtests passed**. The category splits cleanly in two. **(a) The `legacy-mb-*` block (1204 ids, 1197 TIMEOUT)** is dominated by a single survey gap, not an engine defect: every one of those tests loads `/common/subset-tests.js`, which 404s, so `subsetTest is not defined` throws before any test registers, the harness never reports, and the id burns a 10-second TIMEOUT — that block alone is ~3 of the 3.6 hours. [BUG-346](../../bugs/BUG-346-OPEN.md) (`..` segments not collapsed) is visible in the same block, 404ing the category's *own* vendored `../../resources/*.js`. **(b) The root block (58 ids, 30 harness OK)** is the real Encoding-API survey and produced two new bugs. [BUG-356](../../bugs/BUG-356-OPEN.md): `<a>`/`<link>` do not reflect `href` at all and the URL-decomposition IDL attributes (`search`/`pathname`/`protocol`/`host`/`hash`/`origin`) are missing on every element — **451 subtests across 5 files** fail on `a.search.substr(1)` → `Cannot read properties of undefined`, the single largest cause among tests that actually executed. [BUG-357](../../bugs/BUG-357-OPEN.md): `TextDecoder` is a UTF-8-only stub — no label→encoding table (`textdecoder-labels.any.html` 0/222), the constructor never throws `RangeError`, `{fatal:true}` only throws on a truncated tail (50 subtests between them), `decode()` ignores `this.encoding` and always decodes UTF-8 (most of the remaining 694 assertion failures), the BOM is never stripped, and `TextEncoder.encodeInto` does not exist. Both verified outside WPT with `--dump-layout` probes. A further 144 subtests (`encodeInto.any.html` 110, `textdecoder-streaming.any.html` 32, `textdecoder-copy.any.html` 2) fail on `createBuffer is not defined` — the un-vendored `/common/sab.js`, survey gap rather than engine defect. Exactly one file passed completely: `textencoder-constructor-non-utf.any.html` (79/79). See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-27 (коммит `35be3b44`, `tests/wpt/encoding/`, 341 файл: `META.yml`, `WEB_FEATURES.yml`, 54 корневых теста/хелпера, `resources/` — `encodings.js`/`ranges.js`/`single-byte-decoder.js`/`decode-common.js`/`decoding-helpers.js`/`encode-form-common.js`/`encode-href-common.js` + два Python-хендлера + utf-32-фикстуры, `streams/` — 16 файлов, `legacy-mb-japanese/` (euc-jp/iso-2022-jp/shift_jis), `legacy-mb-korean/euc-kr`, `legacy-mb-schinese/` (gb18030/gbk), `legacy-mb-tchinese/big5`, `LICENSE-WPT.md`), в скоупе (⬜, Encoding Standard — `TextEncoder`/`TextDecoder`, `TextEncoderStream`/`TextDecoderStream`, legacy-декодеры/энкодеры). Невендоренные внекатегорийные хелперы: `/common/subset-tests.js`, `/common/sab.js`, `/resources/WebIDLParser.js`+`idlharness.js` — та же методология survey-gap, что `FileAPI`/`ai`/`audio-session`. `run_report.py --all --root encoding --recursive` прошёл полностью за **3 ч 36 мин** (194 отобранных файла → **1262 id**: 93 файла несут `<meta name=variant>` и раскрываются в 1193 `?N-M`-варианта; ни одного HTTPS-порт-гэпа кроме одного `sharedarraybuffer.https.html`): **36/1262 harness OK, 146/2274 сабтестов пройдено**. Категория делится надвое. **(а) legacy-mb-блок — 1204 id, 1197 TIMEOUT**, единая причина: каждый такой тест грузит `/common/subset-tests.js` (не вендорен) и падает на `subsetTest is not defined` до регистрации тестов, поэтому harness не рапортует и id уходит в 10-секундный TIMEOUT — survey-gap, не дефект движка, но именно он съел ~3 из 3.6 часов прогона; поверх него там же виден [BUG-346](../bugs/BUG-346-OPEN.md) (`..`-сегменты не схлопываются — 404 на собственные вендоренные `../../resources/*.js`). **(б) корневой блок — 58 id, 30 harness OK**, и это настоящий срез Encoding API: заведены два бага. [BUG-356](../bugs/BUG-356-OPEN.md) — `<a>`/`<link>` не рефлектят `href` вовсе, а URL-декомпозиционные IDL-атрибуты (`search`/`pathname`/`protocol`/`host`/`hash`/`origin`) отсутствуют на любом элементе: **451 сабтест в 5 файлах** (`gb18030-encoder` 254, `big5-enc-ascii` 123, `gbk-encoder` 49, `big5-encoder` 13, `iso-2022-jp-encoder` 12) падает на `a.search.substr(1)` → `Cannot read properties of undefined`; крупнейшая причина среди реально исполнившихся. [BUG-357](../bugs/BUG-357-OPEN.md) — `TextDecoder` это UTF-8-заглушка: нет таблицы label→encoding (222 сабтеста `textdecoder-labels.any.html`, 0/222), конструктор никогда не бросает `RangeError` и `{fatal:true}` не бросает на невалидных байтах (50 сабтестов), `decode()` игнорирует `this.encoding` и всегда декодирует как UTF-8 (основная масса из оставшихся 694 assert-расхождений), BOM не срезается, `TextEncoder.encodeInto` отсутствует. Оба подтверждены вне WPT через `--dump-layout`-пробы. Ещё 144 сабтеста (`encodeInto.any.html` 110, `textdecoder-streaming.any.html` 32, `textdecoder-copy.any.html` 2) падают на `createBuffer is not defined` — невендоренный `/common/sab.js`, survey-gap. Полностью прошёл один файл — `textencoder-constructor-non-utf.any.html` (79/79)
