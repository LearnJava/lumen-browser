# WPT vendor notes — `fledge`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-28 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-fledge`, `docs/wpt-status.md`), included despite its 🚫 scope note (ad-tech / Privacy Sandbox) by the same standing user decision as `attribution-reporting`/`browsing-topics`/`fedcm`/`fenced-frame`. Same pinned commit `35be3b44`, cone-mode `git sparse-checkout`, 77 files. **The whole category lives under `tentative/`** — there is no top-level `META.yml`/`WEB_FEATURES.yml`, unlike every other category vendored so far. 34 `.window.js` tests (33 of them `.https.`; the exception is `insecure-context.window.js`) + 2 `.html` (`fetch-ad-auction-headers.tentative.https.html`, `fetch-ad-auction-headers-insecure-context.tentative.http.html`) = 36 executable files, expanded by `// META: variant=` lines into **183 manifest ids**; `resources/` (29 files: 18 wptserve Python endpoints — bidding/decision logic, trusted signals, request tracker, update-url — plus `fledge-util.sub.js`/`ba-fledge-util.sub.js`, `worklet-helpers.js`, `service-worker-helper.js`, `incrementer.wasm`, `set-cookie.asis`, `ba-public-keys`); `third_party/` with three vendored JS libraries (cbor-js, hpke-js, noble-ed25519), each keeping its own `LICENSE`/`README`; 3 `.headers` files; `LICENSE-WPT.md`. `incrementer.wasm` is the **first `.wasm` in this repository** — git's `text=auto` detects it as binary on its own, so no `.gitattributes` change was needed (verified: `git diff --cached --stat` reports `Bin 0 -> 46 bytes`). `run_report.py --all --root fledge --recursive` — **3 h 16 min 34 s, 2/183 harness OK, 1/2 subtests** (179 TIMEOUT, 2 ERROR, 2 `Test OK`). **This category inverts the `grep -rl testdriver` cost predictor.** All 35 test files pull `testdriver.js`, which by the `fedcm`/`fenced-frame` rule predicts an instant SKIP wall; the run produced **zero** SKIPs, because `MANIFEST.json` sets `testdriver: true` on **0 of the 183 ids** — the manifest generator derives that flag from `<script src=…testdriver.js>` in HTML sources, while `.window.js`/`.any.js` pull the same file via `// META: script=/resources/testdriver.js`, which never becomes the flag. Every id therefore reached the HTTPS-port gap and paid a full ~65 s TIMEOUT. Predict from the manifest flag, not from a source grep. Only the two non-HTTPS ids produced signal: `insecure-context.window.html` passed 1/1 (it asserts the Protected Audience API is unavailable in an insecure context — it passes precisely because Lumen implements none of it), and `fetch-ad-auction-headers-insecure-context.tentative.http.html` failed 0/1 on `fetch: network error for ./resources/empty.html` — BUG-347, not fledge. Each of those two poisoned the id that followed it (BUG-380, a finding of the run itself: the executor neither checks the outcome of `browsingContext.navigate` nor clears `window.__lumen_wpt_results`, so a failed navigation immediately reads the previous test's results and raises `AssertionError` instead of a honest TIMEOUT). Protected Audience has no implementation in the engine at all, so the `--dump-layout` probe went one level up, onto the objects the category's tests stand on, and produced five findings: BUG-375 (`URL` has one working setter out of ten — `prop()` installs an empty function instead of omitting the setter, so `url.search = …`, the idiom the category's central helper builds every URL with, is swallowed silently even under `"use strict"`), BUG-376 (`window.location = 'url'` overwrites the Location object with a string instead of navigating; assigning to `location`'s components does not navigate either and desynchronises the object from `href`), BUG-377 (`Node.baseURI` missing on every node type — `fledge-util.sub.js` dies on its third line), BUG-378 (604 engine-internal names are own properties of `window`, 592 enumerable, all writable, and the shim resolves natives through the global at call time — overwriting `window._lumen_get_attr` hijacks `Element.getAttribute` page-wide), BUG-379 (the anti-automation-detection guard is itself a fingerprint: it defines 15 markers as non-configurable own properties that Chrome and Firefox have zero of). Out-of-category helpers not vendored: `/common/utils.js`, `/resources/testdriver.js`+`testdriver-vendor.js` — the same documented survey gap as `fetch`/`fenced-frame`. Side effect of this run: `tests/wpt/config.json`'s HTTP ports moved 8300/8301 → 18300/18301 after three failed runs — the old pair sat inside this machine's ephemeral range (1024-15000) and was taken by an unrelated process (see the Troubleshooting section of `tests/wpt/README.md`). See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-28 (коммит `35be3b44`, `tests/wpt/fledge/`, 77 файлов: всё дерево лежит под `tentative/` — у категории нет ни `META.yml`, ни `WEB_FEATURES.yml` на верхнем уровне; 34 `.window.js` (33 из них `.https.`) + 2 `.html` = **36 исполняемых файлов**, `resources/` из 29 хелперов и wptserve-эндпоинтов (18 `.py`), `third_party/` с тремя вендоренными JS-библиотеками (cbor-js, hpke-js, noble-ed25519) со своими лицензиями, `incrementer.wasm` — первый `.wasm` в репозитории, 3 `.headers`, `LICENSE-WPT.md`), скоуп 🚫 (ad-tech, Privacy Sandbox), включена по постоянному решению пользователя. `run_report.py --all --root fledge --recursive` — **3 ч 16 мин 34 с, 2/183 harness OK, 1/2 сабтеста**: 179 TIMEOUT, 2 ERROR, 2 `Test OK`. **Главный методологический результат — предсказатель стоимости по `grep -rl testdriver` здесь инвертируется.** Все 35 тестовых файлов тянут `testdriver.js`, что по правилу `fedcm`/`fenced-frame` предсказывает мгновенную стену SKIP; фактически SKIP-ов **ноль**, потому что в `MANIFEST.json` флаг `testdriver: true` стоит у **0 из 183** id: генератор манифеста выставляет его по `<script src=…testdriver.js>` в HTML-исходнике, а `.window.js`/`.any.js` подключают тот же файл строкой `// META: script=/resources/testdriver.js`, которая в флаг не превращается. Поэтому каждый id доходит до HTTPS-порт-гэпа и платит полный ~65-секундный TIMEOUT (`invalid url: invalid port: "None"`, 181 строка) — 3 ч 16 мин вместо ожидавшихся минут. Правило на будущее: считать долю testdriver по флагу в манифесте, а не по грепу исходников; для категорий из `.window.js`/`.any.js` предсказатель testdriver не работает вовсе. Сигнал дали ровно два не-HTTPS id: `insecure-context.window.html` — **`Test OK`, 1/1 сабтест PASS** (тест утверждает, что API Protected Audience недоступны в незащищённом контексте, и проходит именно потому, что в Lumen их нет вовсе), и `fetch-ad-auction-headers-insecure-context.tentative.http.html` — `Test OK`, 0/1: единственный сабтест падает на `fetch: network error for ./resources/empty.html`, т.е. на уже заведённом [BUG-347](../bugs/BUG-347-OPEN.md) (`fetch()` не резолвит относительные URL), а не на самом fledge. Оба исполнившихся теста «отравили» следующий за собой id — это [BUG-380](../bugs/BUG-380-OPEN.md), находка самого прогона: исполнитель не проверяет исход `browsingContext.navigate` и не очищает `window.__lumen_wpt_results`, поэтому при неудачной навигации немедленно вычитывает результаты предыдущего теста и роняет `AssertionError` вместо честного TIMEOUT (2 из 2 `ERROR` в прогоне). API Protected Audience в движке не реализован ни строкой (`grep -riE 'joinAdInterestGroup|runAdAuction|interestGroup|fledge' crates/` — пусто), поэтому проба `--dump-layout` шла «на уровень выше» — по объектам, на которые опираются тесты категории: [BUG-375](../bugs/BUG-375-FIXED.md) (у `URL` работал один сеттер из десяти — хелпер `prop()` ставил пустую функцию вместо отсутствующего сеттера, так что присваивание терялось молча даже в strict mode; плюс односторонний `searchParams` и константные `username`/`password`; ценник — `fledge-util.sub.js::createTrackerURL` строит каждый URL через `url.search = …`; **ЗАКРЫТ 2026-08-10**), [BUG-376](../bugs/BUG-376-OPEN.md) (`window.location = 'url'` затирает объект `Location` строкой вместо навигации; присваивание компонентам `location` тоже не навигирует и рассинхронизирует объект с `href`; 258 обращений к `window.location` в тестах категории), [BUG-377](../bugs/BUG-377-OPEN.md) (`Node.baseURI` отсутствует у всех типов узлов — `'baseURI' in document` даёт `false`; `fledge-util.sub.js` падает на третьей строке), [BUG-378](../bugs/BUG-378-OPEN.md) (604 внутренних имени движка — own-свойства `window`, 592 перечисляемы; перезапись `window._lumen_get_attr` подменяет `Element.getAttribute` для всей страницы, т.к. шим резолвит нативы через глобал — общий случай BUG-371), [BUG-379](../bugs/BUG-379-OPEN.md) (защита от детекта автоматизации сама является отпечатком: создаёт 15 маркеров `__playwright`/`__webdriver_evaluate`/… как неустранимые own-свойства, которых в Chrome и Firefox нет ни одного). `CAPABILITIES.md` поправлена в трёх местах: `URL` с ✅ на 🟡, оговорка про `Location` в Navigation, оговорка про фингерпринт глобала в Privacy/Shields.
