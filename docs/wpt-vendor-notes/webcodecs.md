# WPT vendor notes — `webcodecs`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-09 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-webcodecs`, `docs/wpt-status.md`), scope 🚫 (no hardware/software codec pipeline). Same pinned commit, `git sparse-checkout add` at the same commit hash, `LICENSE-WPT.md` copied from the sibling `webauthn` category, 134 files (`META.yml`, `README.md`, `WEB_FEATURES.yml`, binary fixtures — `.gif`/`.mp4`/`.avif`/`.webp` — plus the test `.any.js`/`.html`/`.sub.html` files). No `variant` hits, no `testdriver.js` hits; 55 of 77 selectable files `.https.` (16 additionally `crossOriginIsolated`); one out-of-category dependency, `../webrtc/RTCPeerConnection-helper.js` (unvendored, referenced by one `.https.` test). `run_report.py --all --root webcodecs --recursive --processes=4` completed in ~13:11 (126 selected ids): **18/126 harness OK, 27/214 subtests passed**. 103 TIMEOUT on the standard TLS `UnknownIssuer` gap ([BUG-657](../../bugs/BUG-657-OPEN.md)), 7 ERROR reconfirming already-open [BUG-380](../../bugs/BUG-380-FIXED.md) (browsing-context reuse after a failed navigation returns the previous test's stale results). Of the 18 harness-OK tests, the dominant subtest-failure cluster (79+ of 214) is not the acknowledged Phase-0 "no codec backend" gap (`crates/js/src/web_codecs.rs`'s own doc comment, `CAPABILITIES.md`) but a narrower defect requiring no codec at all — `VideoFrame`'s constructor never reads its `data` source argument (canvas/`ImageBitmap`/frame) at all, so `codedWidth`/`codedHeight` stay `0` unless passed explicitly, and the class has no `allocationSize()`/`copyTo()`/`displayWidth`/`displayHeight`/`visibleRect`/`colorSpace` whatsoever; `AudioData`'s constructor likewise never stores `init.data`, so its `copyTo()` is a hardcoded no-op with nothing to copy; `EncodedVideoChunk`/`EncodedAudioChunk` *do* store their payload (`this._data = init.data`) yet `copyTo()` is still a hardcoded no-op that ignores it; `globalThis.VideoColorSpace` is never installed. Filed as [BUG-710](../../bugs/BUG-710-OPEN.md). A secondary signal — `ctx.drawImage`/`ctx.fillText is not a function` on an `OffscreenCanvas.getContext('2d')` result, hit by 5 of the 18 harness-OK tests — is a reconfirmation of the already-documented gap (`CAPABILITIES.md`: OffscreenCanvas's 2D context is "a separate 16-member shim against the element context's 59, with no `save`/`restore` at all"), not a new finding. See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-09 (`tests/wpt/webcodecs/`, 134 файла), нет аппаратного/софт кодек-конвейера. `run_report.py --all --root webcodecs --recursive --processes=4` (~13 мин, 126 отобранных id): **18/126 harness OK, 27/214 сабтестов**. 103 TIMEOUT на TLS-гэпе `UnknownIssuer` ([BUG-657](../../bugs/BUG-657-OPEN.md)).
