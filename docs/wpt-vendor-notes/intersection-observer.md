# WPT vendor notes — `intersection-observer`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-05 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-intersection-observer`, `docs/wpt-status.md`), scope ⬜ (candidate). Same pinned commit, `git sparse-checkout add` at the same commit hash, 116 files (`META.yml`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` copied from the sibling `inert` category, 143 selected test ids across the top level and a `v2/` subdirectory, one shared `resources/intersection-observer-test-utils.js` helper). No `testdriver.js` hits, 13 `.https.`/`.sub.html` files. `run_report.py --all --root intersection-observer --recursive` completed in ~11:17 (148 all-vendored, 143 selected ids): **81/143 harness OK, 5/151 subtests passed**. Three new bugs, all confirmed live via `--mcp-live-port`: [BUG-628](../bugs/BUG-628-OPEN.md) (`IntersectionObserver.prototype.takeRecords` missing entirely, plus `root`/`rootMargin`/`thresholds` have no getters at all — dominant cause, 68/143 files call `takeRecords()` as routine boilerplate and fail before their own assertions), [BUG-626](../bugs/BUG-626-OPEN.md) (constructor/`observe()` perform no argument validation — no `RangeError`/`TypeError`/`SyntaxError` where the spec requires one, `observe(non-Element)` silently no-ops instead of throwing), [BUG-627](../bugs/BUG-627-OPEN.md) (`options.root`/`options.scrollMargin` accepted but never read in the delivery function — every observer always intersects against the top-level viewport). `CAPABILITIES.md` downgraded ✅→🟡 for `IntersectionObserver`, same drift class as BUG-368. Remaining failures reconfirm already-open defects: [BUG-368](../bugs/BUG-368-OPEN.md) (`ShadowRoot.innerHTML` text-node stub breaks `shadow-content.html`), [BUG-384](../bugs/BUG-384-OPEN.md) (named access on Window — bare `target`/`container`/`iframe`/`frame`/`r` identifiers), [BUG-346](../bugs/BUG-346-OPEN.md) (`Url::resolve()` doesn't collapse `..`, 404s on `v2/../resources/...`), [BUG-482](../bugs/BUG-482-OPEN.md) (`document.scrollingElement` missing). One un-vendored out-of-category dependency, not an engine bug: `/common/rendering-utils.js` (`waitForAtLeastOneFrame` and friends, used by the `transformed-iframe-*`/`root-margin-in-same-origin-iframe` family). See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/intersection-observer/`, 116 файлов: `META.yml`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` скопирован из соседней `inert`, тестовые файлы верхнего уровня + подкаталог `v2/`, один общий `resources/intersection-observer-test-utils.js`), скоуп ⬜ (кандидат). `run_report.py --all --root intersection-observer --recursive` — ~11:17, 143 отобранных id: **81/143 harness OK, 5/151 сабтестов**.
