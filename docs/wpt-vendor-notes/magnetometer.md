# WPT vendor notes — `magnetometer`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-05 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-magnetometer`, `docs/wpt-status.md`), included despite its 🚫 scope note (device sensor) by the same standing user decision as `accelerometer`/`ambient-light`/`compute-pressure`. Same pinned commit, `git sparse-checkout add` at the same commit hash, 16 files (`META.yml`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` copied from the sibling `keyboard-lock` category, `idlharness.https.window.js`, 9 top-level test files (7 `.https.`), `resources/sensor-data.js`). Out-of-category helpers not vendored: `/generic-sensor/generic-sensor-tests.js`+`resources/generic-sensor-helpers.js`, `/page-visibility/resources/window_state_context.js`, `/permissions-policy/resources/permissions-policy.js`, same documented survey gap as `accelerometer`/`FileAPI`. No `variant` hits, 2 `testdriver.js` hits. `run_report.py --all --root magnetometer --recursive` completed in ~1:56 (10 selected ids): **2/10 harness OK, 1/3 subtests passed**. 6 `.https.` ids (permissions-policy + iframe-access) TIMEOUT on the standard self-signed-cert TLS gap (`network error: TLS handshake: invalid peer certificate: UnknownIssuer`, same class as `keyboard-lock`/`keyboard-map`/`loading`); 2 ERROR are a session/URL-reuse artifact of the same class as [BUG-380](../../bugs/BUG-380-FIXED.md) (`Got results from X, expected Y`, hit `Magnetometer.https.html`/`idlharness.https.window.html`). The two ids that actually ran (both non-`.https.`): `Magnetometer-supported-by-permissions-policy.html` — harness OK, 0/1 FAIL (`document.permissionsPolicy.features` doesn't list `magnetometer`, same pattern as `ambient-light`); `Magnetometer_insecure_context.html` — harness OK, 0/1 FAIL (`Magnetometer` is exposed in an insecure HTTP context) — re-confirms already-open [BUG-399](../../bugs/BUG-399-FIXED.md) (`window.isSecureContext` hardcoded `true`, originally found on the identical `Gyroscope_insecure_context.html`) and [BUG-394](../../bugs/BUG-394-FIXED.md) (Generic Sensor constructors don't gate on context themselves), not a new finding — `Magnetometer` shares the same `_makeXyzSensor` stub (`crates/js/src/generic_sensor.rs`) as `Accelerometer`/`Gyroscope`. No bug filed. See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/magnetometer/`, 16 файлов: `META.yml`, `WEB_FEATURES.yml`, `idlharness.https.window.js`, 9 тестовых файлов верхнего уровня (7 `.https.`), `resources/sensor-data.js`), включена несмотря на скоуп 🚫 (датчик устройства) по тому же постоянному решению пользователя, что `accelerometer`/`ambient-light`/`compute-pressure`. Внекатегорийные хелперы не довендорены: `/generic-sensor/generic-sensor-tests.js`+`resources/generic-sensor-helpers.js`, `/page-visibility/resources/window_state_context.js`, `/permissions-policy/resources/permissions-policy.js` — та же методология, что `accelerometer`/`FileAPI`. `run_report.py --all --root magnetometer --recursive` — ~1:56, 10 отобранных id: **2/10 harness OK, 1/3 сабтестов**. 6 `.https.` (permissions-policy + iframe-access) TIMEOUT на стандартном TLS-гэпе тестового сертификата (`network error: TLS handshake: invalid peer certificate: UnknownIssuer`, тот же класс, что `keyboard-lock`/`keyboard-map`/`loading`); 2 ERROR — session/URL-reuse артефакт того же класса, что [BUG-380](../../bugs/BUG-380-FIXED.md) (`Got results from X, expected Y`, задело `Magnetometer.https.html`/`idlharness.https.window.html`). Из 2 реально исполнившихся не-https тестов: `Magnetometer-supported-by-permissions-policy.html` — harness OK, 0/1 FAIL (`document.permissionsPolicy.features` не перечисляет `magnetometer`, тот же паттерн, что `ambient-light`); `Magnetometer_insecure_context.html` — harness OK, 0/1 FAIL (`Magnetometer` доступен в небезопасном HTTP-контексте) — переподтверждает уже открытый [BUG-399](../../bugs/BUG-399-FIXED.md) (`window.isSecureContext` захардкожен `true`, найден на идентичном `Gyroscope_insecure_context.html`) и [BUG-394](../../bugs/BUG-394-FIXED.md) (Generic Sensor конструкторы не гейтятся по контексту сами по себе), не новая находка — Magnetometer использует тот же общий `_makeXyzSensor`-стаб (`crates/js/src/generic_sensor.rs`), что `Accelerometer`/`Gyroscope`. Новых багов не заведено.
