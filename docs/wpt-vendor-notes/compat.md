# WPT vendor notes — `compat`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-25 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-compat`, `docs/wpt-status.md`). Same pinned commit, `git sparse-checkout` at the same commit hash, 56 files — mostly webkit-compat reftest pairs (visual comparison, not testharness.js) plus 11 testharness tests. 9 of the 11 reference only already-vendored `/resources/testharness.js`+`testharnessreport.js`; 2 (`webkit-box-item-shrink-001/002`) additionally reference `/fonts/ahem.css`+`/resources/check-layout-th.js` — not vendored, same documented survey gap as `FileAPI`/`IndexedDB`. `run_report.py --all --root compat --recursive`: 13 selected ids (reftest pairs aren't picked up by this runner — no screenshot-diff support), 10/13 harness OK, 9/71 subtests passed. See `docs/wpt-status.md` for the failure clusters (legacy `webkit*` CSSOM aliases unimplemented, `-webkit-box` vertical centering, lenient `-webkit-gradient()`/`-webkit-radial-gradient()` parsing, `::-webkit-scrollbar` `insertRule` crash).

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-25 (коммит `ed90cf49`, `tests/wpt/compat/`, 56 файлов; в основном webkit-совместимостные reftest-пары, 11 testharness-тестов + 2 не довендорены гэпом ниже). 2 из 11 testharness-тестов (`webkit-box-item-shrink-001/002`) ссылаются на `/fonts/ahem.css`+`/resources/check-layout-th.js` — не вендорены (та же методология survey-gap, что FileAPI/IndexedDB), из-за чего оба TIMEOUT. Прогон `run_report.py --all --root compat --recursive`: 13 отобранных id (reftest-пары не подхватываются этим раннером — исполнитель не поддерживает screenshot-сравнение), 10/13 harness OK, 9/71 сабтестов passed, `idlharness.window.html` тоже TIMEOUT. Замеченные кластеры провалов (не заведены как BUG-NNN — первый проход, см. методологию выше): ни один `webkit*`-алиас (`webkitAlignContent`, `webkitFlexBasis`, `webkitBorderRadius`, …) не выставлен на `CSSStyleDeclaration` — легаси-CSSOM camelCase-алиасы для префиксных свойств вовсе не реализованы (51 сабтест в `css-style-declaration-alias-enumeration.html`, ещё 6 `webkitMaskBoxImage*` в `webkit-mask-box-enumeration.html`); `display: -webkit-box` с `-webkit-box-align` не центрирует потомка по вертикали (легаси webkit-flexbox layout не работает для align); `-webkit-radial-gradient()`/`-webkit-gradient()` парсер слишком нестрогий — не отклоняет пропущенную запятую перед цветовыми стопами и отрицательные радиусы; `insertRule()` с `::-webkit-scrollbar` падает на "Cannot read properties of undefined" — похоже на гэп в доступе к `document.styleSheets`/`sheet`; `-webkit-text-fill-color: currentColor` не наследует реальный цвет
