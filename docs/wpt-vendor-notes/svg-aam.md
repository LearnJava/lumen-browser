## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-06 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-svg-aam`, `docs/wpt-status.md`), scope ⬜ (candidate), spec `https://w3c.github.io/svg-aam/`. Same pinned commit, `git sparse-checkout add` at the same commit hash, 8 files (`META.yml`, `name/` — 3 `comp_*.html` accessible-name computation tests, `role/` — 4 `roles*.html`/`role-img.tentative.html` implicit-role tests, `LICENSE-WPT.md`). Every file is automatically runnable (`testharness`, no `-manual`/ATTAcomm here, unlike `core-aam`/`dpub-aam`). One out-of-category helper not vendored: `/wai-aria/scripts/aria-utils.js` (shared ARIA role-verification harness), same documented gap as `core-aam`/`dpub-aam`/`graphics-aam`/`graphics-aria`/`html-aam` — `wai-aria` itself isn't vendored yet (`WPT-VENDOR-wai-aria`, ROADMAP.md:560). `run_report.py --all --root svg-aam --recursive` completed in 1:39 (7 selected ids): **0/7 harness OK, 0/0 subtests** — all 7 TIMEOUT, not SKIP: same predictor-inversion class as `html-aam`/`fledge` (the manifest doesn't flag `testdriver: true` on these files despite them pulling `testdriver.js`/`testdriver-actions.js`/`testdriver-vendor.js`, so instead of an instant SKIP they navigate, hit `ReferenceError: AriaUtils is not defined` inside a `script error`, and hang to the wptrunner timeout). New finding — [BUG-686](../../bugs/BUG-686-OPEN.md), found by a direct engine probe (`lumen_a11y::build_ax_tree`) rather than the run itself, per the "probe even without signal" rule: `implicit_role` (`crates/engine/a11y/src/roles.rs:349`) matches only HTML tag names and never checks element namespace, so every SVG tag (`svg`/`circle`/etc.) falls through to `AXRole::Generic` instead of the SVG-AAM implicit-role table — distinct from the already-open [BUG-398](../../bugs/BUG-398-FIXED.md) (explicit `role="graphics-document"` not recognized by `AXRole::parse`, a different function/code path). One new bug number. See `docs/wpt-status.md` for the full breakdown.
