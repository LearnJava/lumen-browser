# WPT vendor notes — `mediacapture-extensions`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-05 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-mediacapture-extensions`, `docs/wpt-status.md`), included despite its 🚫 scope note (media capture — no pipeline) by the same standing user decision as `media-capabilities`/`media-playback-quality`/`media-source`. Same pinned commit, `git sparse-checkout add` at the same commit hash, 6 files (`META.yml`, `LICENSE-WPT.md` copied from the sibling `media-source` category, 5 root test files, all `.https.`). No `variant` hits, no out-of-category dependencies; 2 of 5 files pull `testdriver.js` (`MediaStreamTrack-{audio,video}-stats.https.html`). `run_report.py --all --root mediacapture-extensions --recursive` completed in ~3:17 (5 selected ids): **0/5 harness OK, 0/0 subtests**. All 5 TIMEOUT on the documented TLS `UnknownIssuer` gap (see `docs/wpt-status.md`) — navigation itself never completes, so the testdriver predictor never gets a chance to apply. A `crates/js/src/media_devices.rs` grep confirmed `getUserMedia`/`MediaStreamTrack` are implemented (Phase 1, PH3-3) but the category's own extensions are selectively missing: `MediaStreamTrack.prototype` has no `stats` getter (Media Capture Extensions §4, exercised by the two `MediaStreamTrack-*-stats.https.html` tests), and `getCapabilities()`'s constraint dictionary has no `backgroundBlur`/`eyeGazeCorrection`/`faceFraming` keys (exercised by the three `GUM-*.https.html` tests). No bug filed — first pass of an absent feature, same class as `media-playback-quality`/`measure-memory`. See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/mediacapture-extensions/`, 6 файлов: `META.yml`, `LICENSE-WPT.md` скопирован из соседней `media-source`, 5 тестовых файлов верхнего уровня, все `.https.`), включена несмотря на скоуп 🚫 по тому же постоянному решению пользователя, что `media-capabilities`/`media-playback-quality`/`media-source`. Ни variant-ов, ни out-of-category хелперов; 2 из 5 тянут `testdriver.js` (`MediaStreamTrack-{audio,video}-stats.https.html`).
