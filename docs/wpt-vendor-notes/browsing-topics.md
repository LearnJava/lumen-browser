## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-25 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-browsing-topics`, `docs/wpt-status.md`), included despite its 🚫 scope note (ad-tech / Privacy Sandbox) by the same standing user decision as `attribution-reporting`/`accelerometer`/`acid`/`ai`/`ambient-light`/`appmanifest`/`audio-output`/`audio-session`/`autoplay-policy-detection`/`background-fetch`/`background-sync`/`badging`/`battery-status`/`bluetooth`. Same pinned commit, `git sparse-checkout` at the same commit hash, 18 files (`WEB_FEATURES.yml`, 13 test files, `resources/` — 3 Python handlers + `pixel.png` + 4 JS helpers). No out-of-category helpers. `run_report.py --all --root browsing-topics --recursive` completed in ~2:37 (13 selected ids: 10 `.https.`-only + 3 non-https): 8 `.https.` TIMEOUT (`invalid url: invalid port: "None"`, same HTTPS-port gap as `WebCryptoAPI`/`ai`/`bluetooth`) + 2 `.https.` ERROR (session/URL-reuse artifact, same class as `accelerometer`/`beacon`); `iframe-topics-attribute-insecure-context.tentative.http.sub.html` TIMEOUT via a different path — the file itself is served over plain HTTP but embeds a `{{ports[https][0]}}` placeholder for a nested iframe, and wptserve's own template substitution 500s on the empty `ports["https"]` (same root HTTPS-port gap, surfacing server-side instead of client-side). The 2 remaining non-https tests both ran (harness OK) but failed their sole subtest: `document-api-insecure-context.tentative.http.html` expects a `TypeError` from an explicit `try`/`catch` around `document.browsingTopics()` (unimplemented, expected for a 🚫-scope category) but got `assert_unreached` instead — the call didn't throw at all; `fetch-topics-insecure-context.tentative.http.html` got `fetch error: invalid url: invalid url: missing scheme: "./resources/check-topics-request-header.py"` — a relative URL passed to `fetch()` failed to resolve against the document base, a possible engine gap. 2/13 harness OK, 0/2 subtests. Not filed as a separate BUG-NNN — first pass only vendors + runs. See `docs/wpt-status.md` for details.
