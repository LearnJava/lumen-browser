Почти весь провал сводится к трём уже заведённым багам, а не к дефекту самих импорт-карт: доминирующая причина (22 из 22 TIMEOUT + большинство FAIL) — [BUG-446](../../bugs/BUG-446-FIXED.md) (граф модулей страницы не подгружается: любой `import`/`import()` относительного спецификатора внутри уже загруженного модуля падает `module '<url>' not found», независимо от того, есть импорт-карта или нет — `set_import_map` из фикса BUG-350 переименовывает спецификатор, но загружать переименованный URL по-прежнему некому); часть `not-overridden/*`/`nonimport-integrity.html`/`static-integrity.html` падает на [BUG-485](../../bugs/BUG-485-FIXED.md)/[BUG-565](../../bugs/BUG-565-FIXED.md) (`document.head` всегда `undefined` — тесты создают `<script>`/`<link>` через `document.head.appendChild`); `script-supports-importmap.html` падает на уже заведённый [BUG-572](../../bugs/BUG-572-OPEN.md) (`HTMLScriptElement.supports` не существует). Отдельно проверено: `static-integrity.html`'s 2 «прошедших» сабтеста (`log` остаётся `[]`) — ложноположительные, модуль не грузится по BUG-446 независимо от корректности integrity-хэша, а не потому что импорт-карт-специфичная проверка `integrity` (Import Maps §"Integrity metadata") реально работает. Новых багов не заведено — весь сигнал воспроизводит уже открытые дефекты; после фикса BUG-446 категорию стоит перепрогнать.
