Almost all unexpected results are `assert_implements: LargestContentfulPaint is not implemented`/`assert_implements: PerformancePaintTiming is not implemented` — a `crates/js/src/dom.rs` grep found nothing beyond a comment referencing Resource Timing L2, neither `LargestContentfulPaint` nor `PerformancePaintTiming` is implemented at all; 8 more FAIL on `assert_own_property: ResourceTiming not supported expected property "PerformanceResourceTiming"` — also unimplemented. No bug filed: same pattern as `keyboard-lock`/`keyboard-map`/`js-self-profiling`, a first pass documenting an absent candidate feature, not a defect in an existing one. ## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/largest-contentful-paint/`, 78 файлов: `META.yml`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` скопирован из соседней `keyboard-map`, 68 тестовых файлов верхнего уровня (2 `.https.`), `resources/largest-contentful-paint-helpers.js`+`invisible-images.js`, `animated/`), скоуп ⬜ (кандидат, Largest Contentful Paint API). Подавляющее большинство unexpected (104+2 упоминания в логе, покрывают почти все FAIL) — `assert_implements: LargestContentfulPaint is not implemented`/`assert_implements: PerformancePaintTiming is not implemented`: PerformanceObserver-based Largest Contentful Paint API целиком отсутствует, грep `crates/js/src/dom.rs` подтвердил — единственное упоминание темы это комментарий про Resource Timing L2, ни `LargestContentfulPaint`, ни `PerformancePaintTiming` не реализованы. 8 FAIL дополнительно бьют в `assert_own_property: ResourceTiming not supported expected property "PerformanceResourceTiming"` — тоже не реализовано.
