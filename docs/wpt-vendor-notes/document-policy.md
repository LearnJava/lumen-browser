## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-26 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-document-policy`, `docs/wpt-status.md`), in-scope (⬜, Document Policy — the `Document-Policy` HTTP response header + reflected `iframe.policy`/`document.policy` API restricting features like `sync-xhr` and enforcing a required policy on child frames; not implemented in Lumen at all, `Document-Policy` unrecognized by `crates/network`). Same pinned commit, `git sparse-checkout` at the same commit hash, 27 files (`META.yml`, `echo-policy.py`+`echo-policy-nested.html`(+`.headers`) — a recursive-iframe echo fixture, `experimental-features/` — 3 `.tentative.html` tests + `resources/` (`common.js`, `compressed.css`, `compressed.json`, `video.webm`), `reporting/` — 2 tests + shared `resources/document-policy-report-json.js`, `required-policy/` — 6 tests). No out-of-category helpers — every test references only the already-vendored `/resources/testharness.js`+`testharnessreport.js` (plus the category's own `resources/document-policy-report-json.js`). `run_report.py --all --root document-policy --recursive` selected 11 ids by file scan and completed fully (~1:47): `echo-policy-nested.html` is a plain iframe-recursion fixture (no `testharness.js`), correctly excluded by the manifest as not a test, leaving 10 queued tests. 3/10 harness OK, 0/19 subtests passed, 7 TIMEOUT. Failure clusters: `network-efficiency-guardrails-json.tentative.html` FAIL on `fetch('./resources/compressed.json')` — `TypeError: fetch: network error`, the same relative-URL-resolution gap already root-caused as [BUG-347](../../bugs/BUG-347-OPEN.md) (`custom-elements`, also seen in `browsing-topics`/`client-hints`/`cors`/`connection-allowlist`); its two siblings (`network-efficiency-guardrails.tentative.html`, `-report-only.tentative.html`, which load `<link rel=stylesheet href="./resources/compressed.css">` instead of `fetch()`) TIMEOUT waiting on the same unimplemented Network Efficiency Guardrails signal; `reporting/sync-xhr-report-only.html`+`sync-xhr-reporting.html` FAIL with `Cannot read properties of undefined (reading 'href')` — no Document-Policy violation report is ever generated (`document.policy`/reporting integration absent), so the test's `reports[0]` is `undefined`; all 6 `required-policy/*.html` tests TIMEOUT — `iframe.policy` (the reflected content attribute for `required-document-policy`) isn't implemented, so parent/child required-policy negotiation never happens and the child's postMessage-based report never arrives. Root cause for the whole category is a single unimplemented feature (the `Document-Policy` header/API doesn't exist in Lumen at all) plus one already-known infra gap (BUG-347) for one test — not filed as a separate BUG-NNN. See `docs/wpt-status.md` for details.
