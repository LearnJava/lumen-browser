## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-04 (коммит `35be3b44`, `tests/wpt/html-ruby-extensions/`, 195 файлов: `README.md`, `LICENSE-WPT.md`, 84 тестовых `html-ruby-NNN.html`, `reference/` с mismatch-эталонами), скоуп ⬜ (кандидат). Категория **на 100% ручная по замыслу спеки** (README: "these are manual tests… simply relying on automated reports of tests passing is not sufficient") — все тестовые файлы `rel=mismatch` reftest, ни `-manual`-суффикса в имени. `run_report.py --all --root html-ruby-extensions --recursive` — **~1 с, 0/0**: `wptrunner` отбирает все 84 id, но роняет их `Unsupported test type reftest` (тот же класс гэпа, что `acid`/`accessibility` — reftest-исполнитель не реализован, S8 в `docs/tasks/p2-wpt-integration.md`).
