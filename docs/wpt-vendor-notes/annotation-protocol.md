# WPT vendor notes — `annotation-protocol`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-23 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-annotation-protocol`, `docs/wpt-status.md`). Same pinned commit, `git sparse-checkout` at the same commit hash, 58 files (`files/annotations/` — 43 JSON/JSON-LD fixtures + `*.headers`, `files/index.html` — a manual client-testing target page, `server/server-manual.html` — the sole test file, `tools/protocol-server.py` — reference protocol server). One out-of-category helper (`/common/utils.js`, used by `server-manual.html`) not vendored, same documented survey gap as `FileAPI`/`ai`. Entirely manual by spec design like `annotation-model` (README: no general automation mechanism, workflow requires a human driving an annotation client/server) — the sole test file is `-manual.html` and gets excluded by `run_report.py`'s own filter; the one remaining non-`-manual` candidate, `files/index.html`, isn't a test at all (no `testharness.js`, just a fixture page) so the WPT manifest can't find it (`CRITICAL Unable to find any tests at the path(s)`), crashing the run before `suite_end` — 0/0. Second vendored category with zero automatically runnable tests after `annotation-model`, here surfacing as an explicit manifest error instead of a silent `no tests selected`. See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-23 (`tests/wpt/annotation-protocol/`, 58 файлов: `files/annotations/` — 43 JSON/JSON-LD аннотации-фикстуры + `*.headers`, `files/index.html` — HTML-страница-цель для ручного клиентского тестирования, `server/server-manual.html` — единственный тестовый файл, `tools/protocol-server.py` — эталонный сервер протокола). Внекатегорийный хелпер `/common/utils.js` (используется `server-manual.html`) не довендорен, та же методология, что `FileAPI`/`ai`. Категория целиком ручная по дизайну спеки (README: «no general automation mechanism», рабочий процесс требует человека, запускающего клиент/сервер аннотаций вручную) — единственный тестовый файл носит суффикс `-manual.html`, поэтому `run_report.py --all --root annotation-protocol --recursive` его исключает; единственный оставшийся кандидат `files/index.html` (не `-manual`, но и не тест — фикстура-страница без `testharness.js`) даёт `CRITICAL Unable to find any tests at the path(s)` (манифест WPT не классифицирует его как тест) — прогон крашится до `suite_end`, 0/0. Вторая вендоренная категория без единого автоматически прогоняемого теста после `annotation-model`, здесь единственный кандидат явно ошибается вместо тихого исключения. Не заводился отдельный BUG-NNN — не движковый баг, а изначально задуманный тип тестирования спеки
