# WPT vendor notes — `appmanifest`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-24 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-appmanifest`, `docs/wpt-status.md`), included despite its 🚫 scope note (PWA installation) by the same standing user decision as `accelerometer`/`acid`/`ai`/`ambient-light`. Same pinned commit, `git sparse-checkout` at the same commit hash, 253 files (`META.yml`, `WEB_FEATURES.yml`, 19 `*-member/` subcategories). No out-of-category helpers. Entirely manual by spec design — Web App Manifest is tested by installing a PWA by hand and observing the result, so every real test file is `-manual.html`/`-manual.tentative.html`/`-manual.sub.html`, excluded by `run_report.py`'s own filter. The filter still picked up 5 candidates that aren't tests at all: pass/fail/shortcut landing pages with no `testharness.js` that the manual test opens as a navigation target (`shortcuts-member/shortcut_fail.html`, `shortcuts-member/shortcut_pass.html`, `shortcuts_localized-member/shortcut_pass.html`, `start_url-member/fail.html`, `start_url-member/pass.html`); the WPT manifest can't find them as tests (`CRITICAL Unable to find any tests at the path(s)`), so `run_report.py --all --root appmanifest --recursive` crashes before `suite_end`, 0/0 — the same class of gap as `files/index.html` in `annotation-protocol`. See `docs/wpt-status.md` for details.
