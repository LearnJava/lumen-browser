Same pinned commit, `git sparse-checkout add` at the same commit hash, 4 files (`META.yml`, `LICENSE-WPT.md` copied from the sibling `magnetometer` category, 2 top-level test files, `resources/managed-configuration-helper.js`). No `variant` hits, no `testdriver.js` hits, both files `.https.`. `run_report.py --all --root managed --recursive` completed in ~48 s (2 selected ids): **0/2 harness OK, 0/0 subtests**. A `crates/js/src/dom.rs` grep for `managed`/`ManagedConfig` found nothing — the Managed Configuration API is entirely unimplemented (`managed-config-success.https.window.js` would additionally fail on the missing Chromium-only `ManagedConfigTest` mock even without the TLS gap, per the upstream test's own `// META` comment). No bug filed: same pattern as `keyboard-lock`/`keyboard-map`, a first pass documenting an absent candidate feature. See `docs/wpt-status.md` for the full breakdown.
