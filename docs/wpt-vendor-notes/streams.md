# WPT vendor notes — `streams`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-06 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-streams`, `docs/wpt-status.md`), scope ⬜ (candidate). Same pinned commit, `git sparse-checkout add` at the same commit hash, `LICENSE-WPT.md` copied from the sibling `js` category, 122 files (`piping/`, `queuing-strategies-size-function-per-global.window.js`, `queuing-strategies.any.js`, `readable-byte-streams/`, `readable-streams/`, `resources/`, `transferable/`, `transform-streams/`, `writable-streams/`, `idlharness.any.js`). No `variant` hits, no `testdriver.js` references, only 3 `.https.` files — self-contained aside from `/common/gc.js` (not vendored, same documented survey gap as `FileAPI`/`custom-elements`/`js`) and its own `../resources/*.js` relative imports, which hit the already-open dot-segment bug below. `run_report.py --all --root streams --recursive` completed in 5:50 (88 selected ids): **55/88 harness OK, 154/1076 subtests**. Dominant signal (~200 FAIL, `recordingReadableStream`/`recordingWritableStream`/`delay`/`readableStreamToArray is not defined`) reconfirms [BUG-346](../../bugs/BUG-346-FIXED.md) (`Url::resolve()` doesn't collapse `..`-segments — `streams/piping/../resources/recording-streams.js` 404s even though the file is vendored at `streams/resources/recording-streams.js`). Missing `byobRequest`, and `pull()`/`flush()` never being re-invoked after the first call, match the engine's own documented Phase 0 design (`crates/js/src/dom.rs:5630-5634`: "synchronous-friendly model … async pull callbacks are not re-invoked") — not a bug. New finding — [BUG-684](../../bugs/BUG-684-FIXED.md): `ReadableStream`/`WritableStream`/`TransformStream` are plain ES5 constructors with no `new.target` guard, so calling any of them without `new` silently succeeds and leaks the constructor's fields onto `globalThis` (`TransformStream()` leaks `globalThis.readable`/`globalThis.writable`); same defect class as [BUG-629](../../bugs/BUG-629-FIXED.md)/[BUG-374](../../bugs/BUG-374-FIXED.md)/[BUG-672](../../bugs/BUG-672-FIXED.md)/[BUG-681](../../bugs/BUG-681-FIXED.md). Separately, `ReadableStream.prototype[Symbol.asyncIterator]`/`.values()` are missing entirely (WHATWG Streams §4.1), explaining the run's `s[Symbol.asyncIterator] is not a function` cluster. Confirmed live via `--mcp-live-port`. See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-06 (коммит `35be3b44`, `tests/wpt/streams/`, 122 файла: `META.yml`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` скопирован из соседней `js`, `idlharness.any.js`, `piping/`, `queuing-strategies*.{any,window}.js`, `readable-byte-streams/`, `readable-streams/`, `resources/`, `transferable/`, `transform-streams/`, `writable-streams/`). Ни variant-ов, ни `testdriver.js`; всего 3 `.https.`-файла — самодостаточна, кроме невендоренного `/common/gc.js` (тот же survey-gap, что `FileAPI`/`custom-elements`/`js`) и собственных относительных `../resources/*.js`-импортов, упирающихся в уже открытый дефект резолвинга ниже. Прогон `run_report.py --all --root streams --recursive` (5:50, 88 отобранных id): **55/88 harness OK, 154/1076 сабтестов**. Доминирующий сигнал (~200 FAIL, `recordingReadableStream`/`recordingWritableStream`/`delay`/`readableStreamToArray is not defined`) — переподтверждение [BUG-346](../../bugs/BUG-346-FIXED.md) (`Url::resolve()` не схлопывает `..`-сегменты: `streams/piping/../resources/recording-streams.js` 404-ит, хотя файл реально вендорен по `streams/resources/recording-streams.js`). Отсутствие `byobRequest` и повторных вызовов `pull()`/`flush()` соответствует собственному doc-комментарию модуля (`crates/js/src/dom.rs:5630-5634`, «synchronous-friendly model», Phase 0) — не баг. Новая находка — [BUG-684](../../bugs/BUG-684-FIXED.md): `ReadableStream`/`WritableStream`/`TransformStream` — обычные ES5-конструкторы без `new.target`-гварда, вызов без `new` молча биндит `this` на `globalThis` и утекает поля конструктора как одноимённые глобалы (`TransformStream()` — худший случай, утекают `globalThis.readable`/`globalThis.writable`); тот же класс, что BUG-629/374/672/681. Отдельно: `ReadableStream.prototype[Symbol.asyncIterator]`/`.values()` отсутствуют целиком (WHATWG Streams §4.1), объясняя кластер `s[Symbol.asyncIterator] is not a function` в самом прогоне. Живая проба через `--mcp-live-port`
