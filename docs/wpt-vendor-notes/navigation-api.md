# WPT vendor notes — `navigation-api`

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/navigation-api/`, 493 файла, `LICENSE-WPT.md` скопирован из соседней `mimesniff`). API реально реализован (`window.navigation`), не заглушка — 0 `.https.`, testdriver-доля низкая (8/450 файлов), без HTTPS-порт-гэпа. Прогон `run_report.py --all --root navigation-api --recursive` (~21 мин, 475 отобранных id): **349/475 harness OK, но только 6/417 сабтестов passed (1.4%)**. Чтение `crates/js/src/navigation_api.rs` подтвердило причину — шим урезан относительно спеки: `NavigationCurrentEntryChangeEvent` глобал отсутствует (`currententrychange` диспатчит голый `Event`), `navigation.updateCurrentEntry()` не реализован, `NavigateEvent.destination` — голый `URL` вместо `NavigationDestination` (нет `sameDocument`/`getState()`/`key`/`id`/`index`), `NavigationHistoryEntry` не наследует `EventTarget` (нет `dispose`). Плюс нетронутый кластер `Cannot read properties of null (reading 'index')` (48 вхождений) на одно-документных тестах — вероятная гонка коммита навигации vs чтения `_lumen_navigation_entries_json()`, причина не установлена. `cross-window/*` тесты фейлятся отдельно, известным классом (нет multi-window/iframe browsing context, BUG-480).
