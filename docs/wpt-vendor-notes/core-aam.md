# WPT vendor notes — `core-aam`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-26 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-core-aam`, `docs/wpt-status.md`), in-scope (⬜, Core Accessibility API Mappings — how ARIA roles/properties map onto platform accessibility APIs; Lumen already has an accessibility tree, Phase 2). Same pinned commit, `git sparse-checkout` at the same commit hash, 289 files: `META.yml`; `aamtests/` — 104 Python files, a pytest-based platform accessibility API test suite (AT-SPI/IAccessible2/AXAPI wrappers under `aamtests/support/`) — an entirely different test framework from wptrunner/testharness.js, never discovered by the WPT browser-test manifest at all; `manual/` — 169 files (168 `*-manual.html` ARIA/AAM verification pages, WPT-manifest type `manual`, requiring a human tester driving a real AT, `+README.md`); `arianotify/` — 14 files (10 `*-manual.html`, `WEB_FEATURES.yml`, `resources/aria-notify-helpers.js`+`aria-notify-iframe-manual-test.html`+`aria-notify-iframe-test.html` — the last one an iframe helper page, not a standalone test); `role/roles-contextual.html` — the sole automatically-runnable `testharness` test in the whole category. Out-of-category helpers not vendored: `/wai-aria/scripts/aria-utils.js`+`ATTAcomm.js`, same documented survey gap as `FileAPI`/`ai` — `aria-utils.js` is required by the one non-manual test, so even past the gap below it would 404. `run_report.py --all --root core-aam --recursive` selected exactly 1 id (every `-manual.html` excluded by `run_report.py`'s own filter, all 104 `aamtests/*.py` invisible to the WPT manifest, `arianotify/resources/aria-notify-iframe-test.html` not a manifest test either): `role/roles-contextual.html` — SKIP (`Executor does not support testdriver.js`, same known executor gap as `accname`/`attribution-reporting`). 0/1 harness OK, 0/0 subtests. Not filed as a separate BUG-NNN — the only candidate test is blocked by two independent known gaps (missing `testdriver.js` support, un-vendored `aria-utils.js`) rather than a fresh Lumen defect; this is now the category with the *fewest* automatically runnable tests found so far (1, vs. 0 in `annotation-model`/`annotation-vocab`/`avif`). See `docs/wpt-status.md` for details.
