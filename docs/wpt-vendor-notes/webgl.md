# WPT vendor notes — `webgl`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-09 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-webgl`, `docs/wpt-status.md`), scope ⬜ (candidate — WebGL 1.0 is genuinely implemented, a software backend with a GLSL ES interpreter, `crates/js/src/webgl_canvas.rs`). Same pinned commit, `git sparse-checkout add` at the same commit hash, `LICENSE-WPT.md` copied from the sibling `svg` category, 12 files (`META.yml`, `WEB_FEATURES.yml`, `common.js`, `idlharness.any.js`, 7 root `.html` tests). No `variant`/`.https.`/`testdriver.js` hits — self-contained aside from the standard `idlharness.any.js` dependency on the unvendored `/resources/idlharness.js`+`/resources/WebIDLParser.js` (same documented survey gap as `FileAPI`). `run_report.py --all --root webgl --recursive` completed in ~38s (8 selected ids): **7/8 harness OK, 7/15 subtests**. Every non-TIMEOUT failure traces to one root cause in `WEBGL_SHIM`'s `_makeContext` (line 82): the WebGL context is a plain object literal with no prototype anyone can name — `WebGLRenderingContext`/`WebGL2RenderingContext` don't exist as globals anywhere in the codebase (`ReferenceError` on `bufferSubData.html`, `instanceof` throws instead of evaluating), and `getContext('webgl2')` calls the exact same `_makeContext` as `getContext('webgl')` (zero WebGL2-only surface). Within WebGL1 the method table itself is incomplete rather than uniformly no-op: `compressedTexImage2D`/`compressedTexSubImage2D` don't exist at all (`TypeError`, not the silent no-op most unimplemented GL calls get), `getSupportedExtensions()` never advertises a compressed-texture extension, the 6-argument `TexImageSource` overload of `texImage2D` (`<img>`/`<canvas>`/`ImageData` source) isn't implemented — only the 9-argument raw-pixel overload exists, so a call with 6 args silently falls through instead of throwing the spec's `TypeError` — and `uniformMatrix2fv` is missing (only `uniformMatrix3fv`/`uniformMatrix4fv` exist). Filed as [BUG-711](../../bugs/BUG-711-OPEN.md). The one TIMEOUT (`idlharness.any.html`) is the standard unvendored-idlharness-helper gap, not new signal. See `docs/wpt-status.md` for the full breakdown.
