# WPT vendor notes — `cors`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-07-26 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-cors`, `docs/wpt-status.md`), in-scope (⬜, Cross-Origin Resource Sharing — already partially implemented in Lumen, `crates/network`). Same pinned commit, `git sparse-checkout` at the same commit hash, 45 files (`META.yml`, `README.md`, `WEB_FEATURES.yml`, `support.js`, 21 root test files — mostly legacy `.htm`, not `.html` — plus `resources/` — 11 helpers, 8 Python handlers + 3 JS/HTML). Out-of-category helpers not vendored: `/common/get-host-info.sub.js` (defines the `CROSSDOMAIN` global), `/common/utils.js` (defines `token()`), same documented survey gap as `FileAPI`/`ai`. This category surfaced a real gap in `run_report.py` itself (not upstream WPT, not a Lumen engine bug): `all_vendored_test_ids()` only recognized `.html` (+`.any.js`/`.window.js`-generated ids), silently dropping `.htm` — a legitimate WPT test extension the upstream manifest treats identically to `.html`. Fixed in the same commit (extension whitelist widened to include `.htm` in both the flat and `--recursive` modes) since without it the survey would have seen only 5 of 26 runnable tests; verified this doesn't change any other already-vendored category's discovered id count (none of them contain `.htm` files). After the fix, `run_report.py --all --root cors --recursive` selected 26 ids and completed fully (~1:44): 9 TIMEOUT with zero subtest data (`credentials-flag.htm`, `preflight-failure.htm`, `redirect-origin.htm`, `redirect-preflight.htm`, `redirect-userinfo.htm`, `remote-origin.htm`, `script-304.html` — a top-level `ReferenceError` from the un-vendored helpers hangs the harness before it reports, same pattern as `beacon`; `image-tainting-in-cross-origin-iframe.sub.html` — TIMEOUT on a cross-origin-iframe scenario, outside the minimal executor's single-window model; `preflight-cache.htm` — TIMEOUT after 5 FAILs); 17 harness OK, 16 of which fail every subtest on `CROSSDOMAIN is not defined`/`token is not defined` (the un-vendored helpers) and one (`access-control-expose-headers-parsing.window.html`) on `TypeError: fetch: network error` for a relative `fetch("resources/access-control-expose-headers.json")`, the same relative-URL-resolution gap as `browsing-topics`/`client-hints`; the sole genuine PASS in the whole category is `request-headers.htm` 1/6 (its other 5 subtests hit the same `CROSSDOMAIN` gap). 1/168 subtests passed. Not filed as a separate BUG-NNN — every failure traces to an already-documented infra gap (un-vendored `/common/*` helpers, relative-fetch resolution, cross-origin iframe), not a fresh engine defect. See `docs/wpt-status.md` for details.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-07-26 (`tests/wpt/cors/`, 45 файлов: `META.yml`, `README.md`, `WEB_FEATURES.yml`, `support.js`, 21 корневых тестовых файла (в основном `.htm`, легаси-расширение), `resources/` — 11 хелперов (8 Python-обработчиков + 3 JS/HTML)), скоуп ⬜ (CORS — уже частично реализовано в Lumen, `crates/network`). Внекатегорийные хелперы не довендорены: `/common/get-host-info.sub.js` (определяет глобаль `CROSSDOMAIN`), `/common/utils.js` (определяет `token()`), та же методология survey-gap, что `FileAPI`/`ai`. Попутно найден и исправлен реальный гэп в собственном тулинге: `run_report.py`'s `all_vendored_test_ids()` фильтровал только `.html` (+ `.any.js`/`.window.js`), но категория `cors` почти целиком состоит из `.htm` — легитимного WPT-расширения, которое манифест апстрима трактует идентично `.html`; без фикса обзор увидел бы только 5 из 26 автопрогоняемых тестов. Исправлено (whitelist расширен на `.htm` в обоих режимах — плоском и `--recursive`), не меняет поведение других уже вендоренных категорий (у них `.htm`-файлов не было). После фикса `run_report.py --all --root cors --recursive` отобрал 26 id и прошёл полностью (~1:44): 9 TIMEOUT без единого сабтеста (`credentials-flag.htm`, `preflight-failure.htm`, `redirect-origin.htm`, `redirect-preflight.htm`, `redirect-userinfo.htm`, `remote-origin.htm`, `script-304.html` — top-level `ReferenceError` из-за невендоренных хелперов вешает гарнес вместо репорта, тот же паттерн, что `beacon`; `image-tainting-in-cross-origin-iframe.sub.html` — TIMEOUT на кросс-origin-iframe сценарии, вне однооконной модели минимального исполнителя; `preflight-cache.htm` — TIMEOUT после 5 FAIL); 17 harness OK, из них 16 test-файлов целиком проваливаются на `CROSSDOMAIN is not defined`/`token is not defined` (невендоренные хелперы) и один (`access-control-expose-headers-parsing.window.html`) — на `TypeError: fetch: network error` при относительном `fetch("resources/access-control-expose-headers.json")`, тот же гэп с разрешением относительных URL, что `browsing-topics`/`client-hints`; единственный настоящий PASS во всей категории — `request-headers.htm` 1/6 (остальные 5 сабтестов там же — `CROSSDOMAIN is not defined`). 1/168 сабтестов passed. Не заводился отдельный BUG-NNN — все провалы трассируются к уже задокументированным инфра-гэпам (невендоренные `/common/*`-хелперы, относительный fetch, кросс-origin iframe), ни одного нового движкового дефекта
