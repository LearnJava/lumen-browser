# WPT vendor notes — `webidl`

## Vendoring (`tests/wpt/VENDOR.md`)

Test category, added 2026-08-09 by the WPT-VENDOR backlog (`ROADMAP.md` `WPT-VENDOR-webidl`, `docs/wpt-status.md`), scope ⬜ (candidate — pure ECMAScript-binding conformance suite, no hardware/platform dependency). Same pinned commit `35be3b44`, `git sparse-checkout add` at the same commit hash, `LICENSE-WPT.md` copied from the sibling `webhid` category, 51 files (`META.yml`, `README.md`, `current-realm.html`, `idlharness.any.js`, `ecmascript-binding/` — 46 files covering interface-object shape, legacy-platform-object exotic behavior, DOMException binding, replaceable/lenient-this setters, iterator prototypes). No `variant` hits, no `testdriver.js` hits, only 1 `.https.` file — one of the cheapest and cleanest-signal categories in the backlog by every predictor. `run_report.py --all --root webidl --recursive` completed in ~1:43 (45 selected ids): **37/45 harness OK, 134/324 subtests**.

Two new bugs from the dominant clusters:
- [BUG-714](../../bugs/BUG-714-OPEN.md) — `DOMException` (`crates/js/src/v8_runtime.rs:120-163`, `DOM_EXCEPTION_POLYFILL`) doesn't match the WebIDL "legacy exception" binding shape: `name`/`message`/`code` are own instance data properties instead of prototype accessor getters, the legacy code table still assigns non-zero codes to three names removed by webidl#946, `DOMException()` constructs without `new`, global/`.prototype`/`.prototype.constructor` are enumerable/writable where the spec requires the opposite, no `Symbol.toStringTag`. 25/30 subtests across the five `DOMException-*.any.html` files.
- [BUG-715](../../bugs/BUG-715-OPEN.md) — `DOMTokenList`(`classList`)/`CSSStyleDeclaration`(`style`) (`crates/js/src/dom.rs:1327-1381`/`:1404+`) are ad-hoc object-literal factories with no global constructor and no WebIDL "legacy platform object" indexed-property shape (`domTokenList[0]` doesn't exist as an own property at all, only `.item(i)` works). 20/23 subtests of the four `legacy-platform-object/*.html` files plus 3 of `put-forwards.html`.

The remaining ~140 unexpected subtests reconfirm already-open findings, no new numbers: [BUG-480](../../bugs/BUG-480-OPEN.md) (`<iframe>` has no separate browsing context — `current-realm.html` 0/33 and `window-named-properties-object.html` 0/13 both need `self[0]`/an iframe realm), [BUG-529](../../bugs/BUG-529-OPEN.md) (`window.innerWidth`/`outerHeight`/etc. missing entirely — `replaceable-setter-throws-if-defineownproperty-fails.html` 2/8), [BUG-694](../../bugs/BUG-694-OPEN.md) (`URLSearchParams` has no `Symbol.iterator` — `default-iterator-object.html` 0/3), and the already-documented gap that `/resources/idlharness.js`+`WebIDLParser.js` aren't vendored (`idlharness.any.html` TIMEOUT). A broad remaining pattern (`setter-argument.html` 0/17, part of `put-forwards.html`, `sequence-conversion.html`) is elements/interfaces exposing attributes as own-instance values rather than prototype accessors — same architecture-level theme as [BUG-367](../../bugs/BUG-367-OPEN.md)/[BUG-368](../../bugs/BUG-368-OPEN.md), not filed as a new number here since it spans far more of the shim than this one category's evidence covers.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-09 (коммит `35be3b44`, `tests/wpt/webidl/`, 51 файл, `LICENSE-WPT.md` скопирован из `webhid`). Категория без HTTPS-гэпа и testdriver — почти весь сигнал из исполнившихся тестов. `run_report.py --all --root webidl --recursive` (~1:43, 45 отобранных id): **37/45 harness OK, 134/324 сабтестов**.

Два новых бага:
- [BUG-714](../bugs/BUG-714-OPEN.md) — `DOMException` не соответствует WebIDL-биндингу "legacy exception": `name`/`message`/`code` — собственные data-свойства инстанса вместо accessor-геттеров прототипа, таблица legacy-кодов содержит три устаревших имени (`DOMStringSizeError`/`NoDataAllowedError`/`ValidationError`) с ненулевыми кодами вместо требуемого спекой `0`, конструктор вызывается без `new` без ошибки, глобал/`.prototype`/`.prototype.constructor` перечислимые/writable там, где спека требует обратного, нет `Symbol.toStringTag`. Доминирующий кластер — 25/30 сабтестов пяти файлов `DOMException-*.any.html`.
- [BUG-715](../bugs/BUG-715-OPEN.md) — `DOMTokenList`/`CSSStyleDeclaration` собраны как ad-hoc объектные литералы без глобального конструктора и без индексного WebIDL-поведения "legacy platform object" (`domTokenList[0]` не существует вовсе как собственное свойство, работает только `.item(i)`). 20/23 сабтестов четырёх файлов `legacy-platform-object/*.html` + 3 сабтеста `put-forwards.html`.

Остальные ~140 unexpected — переподтверждения уже открытых находок, новых номеров не заводилось: [BUG-480](../bugs/BUG-480-OPEN.md) (`<iframe>` без browsing context — `current-realm.html` 0/33, `window-named-properties-object.html` 0/13), [BUG-529](../bugs/BUG-529-OPEN.md) (`window.innerWidth`/`outerHeight` и т.п. отсутствуют вовсе), [BUG-694](../bugs/BUG-694-OPEN.md) (`URLSearchParams` без `Symbol.iterator`), задокументированный гэп невендоренных `idlharness.js`/`WebIDLParser.js`. Широкий остаточный паттерн (`setter-argument.html` 0/17, часть `put-forwards.html`, `sequence-conversion.html`) — элементы отдают атрибуты как собственные значения инстанса, а не accessor'ы прототипа, тот же архитектурный класс, что уже открытые [BUG-367](../bugs/BUG-367-OPEN.md)/[BUG-368](../bugs/BUG-368-OPEN.md) — новый номер не заводился, находка шире одной категории.
