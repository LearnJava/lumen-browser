Manifest has 392 testharness ids nominally but `run_report.py` only selects 196 (per-global ids after dedup); the remaining 556 reftest + 252 crashtest ids are `Unsupported test type` for `run_report.py` and finish near-instantly. `run_report.py --all --root mathml --recursive --processes=4` completed in ~6 min (196 selected testharness ids): **81/196 harness OK, 31/700 subtests passed**. Dominant failure signal (300+ `document.body.insertAdjacentHTML is not a function` hits and derived `Cannot read properties of null/undefined` on `tabIndex`/`style`) is not a new finding — it cascades from already-open [BUG-351](../../bugs/BUG-351-FIXED.md) (`insertAdjacentHTML` missing on the live `Element`) and [BUG-368](../../bugs/BUG-368-FIXED.md) (`innerHTML` is a text-only stub): the suite's own shared helper (`support/mathml-fragments.js`) builds MathML fragments via `el.innerHTML = ...`, so subsequent `querySelector` calls find nothing. The remaining signal (`getComputedStyle` empty for `direction`/`mfrac` defaults, `math-shift` unsupported, geometry assertions like `expected 25 got 1008`) re-confirms an already-documented `CAPABILITIES.md` gap: `crates/engine/layout/src/mathml.rs` (668 lines, `math-style`/`math-depth` parsed and computed) has no pipeline callers — `<math>` is never built into the box tree, zero visual effect. No bug filed. See `docs/wpt-status.md` for the full breakdown.

## Прогон и находки (`docs/wpt-status.md`)

Вендорена целиком 2026-08-05 (коммит `35be3b44`, `tests/wpt/mathml/`, 891 файл: `META.yml`, `README.md`, `WEB_FEATURES.yml`, `LICENSE-WPT.md` скопирован из соседней `managed`, `crashtests/` (252 id, reftest/crashtest — не исполняются `run_report.py`, `Unsupported test type`), `presentation-markup/`+`relations/` (556 reftest-id, тот же класс), `support/`, `tools/`). Ни variant-ов, ни `.https.`-файлов. `run_report.py --all --root mathml --recursive --processes=4` — ~6 мин, 196 отобранных testharness-id: **81/196 harness OK, 31/700 сабтестов**. Доминирующий сигнал (300+ упоминаний `document.body.insertAdjacentHTML is not a function` и производные `Cannot read properties of null/undefined` на `tabIndex`/`style`) — не новая находка, а каскад уже открытых [BUG-351](../../bugs/BUG-351-FIXED.md) (`insertAdjacentHTML` отсутствует на живом `Element`) и [BUG-368](../../bugs/BUG-368-FIXED.md) (`innerHTML` — текстовая заглушка): собственный хелпер набора тестов (`support/mathml-fragments.js`) строит MathML-фрагменты через `el.innerHTML = ...`, поэтому `querySelector` после этого не находит вставленные узлы. Остаток сигнала (`getComputedStyle` пустой для `direction`/`mfrac`-дефолтов, `math-shift` не поддержан, geometry-ассерты вроде `expected 25 got 1008`) переподтверждает уже задокументированный в `CAPABILITIES.md` пробел: модуль `crates/engine/layout/src/mathml.rs` (668 строк, `math-style`/`math-depth` парсятся и вычисляются) не подключён к пайплайну — `<math>` не строится в box tree (P1-интеграция отложена), визуального эффекта нет вовсе. Новых багов не заведено.
