# Корпус C: 500 сайтов (200 RU + 300 global)

Прибор паритета с эталоном Chrome ([COMPAT-CORPUS-2](../../ROADMAP.md), отчёт `docs/research/site-compat/report.md` §7.7 этап 1 п.10). Корпус только список страниц; сравнивает с Chrome краулер COMPAT-CORPUS-1 (`scripts/compat_crawl.py`), а до него — `scripts/perf_audit.py --mode compat`.

| Файл | Что |
|---|---|
| `corpus-c-ru.txt`, `corpus-c-global.txt` | строки `slug url`, читаются `perf_audit.py --corpus`; у сайта две строки: главная и `<slug>--inner` |
| `corpus-c.tsv` | метаданные: сегмент, позиция, вес 3/2/1 (позиции 1–50 / 51–200 / остальные), ранг Tranco, категория, источник, статус главной при сборке, URL |
| `corpus-c-categories.txt` | категории, назначенные вручную |
| `scripts/corpus_c_build.py` | сборка с сетью (раз в квартал); `.txt` и `.tsv` руками не править |
| `scripts/corpus_c.py` | `check` (целостность, гейт CI), `plan` (сайты ночи), `run` (план + perf_audit) |

## Как собран

- **Порядок** — Tranco, список `N26LW` от 2026-10-13 (воспроизводится по id). **Допуск** — список CrUX (origin-ы, которые открывают пользователи Chrome): global — корзина ≤10k, RU — ≤100k. Без допуска Tranco даёт CDN, трекеры и DNS-домены, не страницы.
- **RU** — домены `.ru` / `.su` / `.рф` плюс закреплённые бренды (`RU_PINNED`: Госуслуги, банки, маркетплейсы, операторы, госорганы), которым допуск не нужен. **Global** — всё остальное.
- **Исключено**: взрослое и азартные игры (по домену и заголовку, плюс `EXCLUDE`), дубли владельца (один SLD-ярлык = один сайт), инфраструктура.
- **Внутренняя страница** — ссылка с главной на тот же хост, проверена `GET 200 text/html`; у сайтов за стеной — из типовых путей (`/about`, `/help`…). Около 20% сайтов внутренней не имеют (стена антибота или нет открытой ссылки) — в корпусе остаётся одна главная.
- **Стена остаётся в корпусе**: ответ 401/403/429/439/498/503 или нерешённый редирект — предмет наблюдения, а не повод исключить сайт. Ошибка сертификата (корни Минцифры у `cbr.ru`, `t2.ru`) не исключает: проба повторяется без проверки, статус в `.tsv` с пометкой `/tls-unverified`. Недоступные с точки сборки — `unreachable`, главная без проверки.
- Статусы и внутренние URL сняты с одной точки (резидентный IP РФ, 2026-10-14) и со временем устаревают: дрейф ловит прогон, а не пересборка.

## Ночной прогон

`python scripts/corpus_c.py plan --date YYYY-MM-DD` пишет `.tmp/corpus-c/night/<дата>-<точка>.txt`.

- **Каждую ночь** — топ-100 RU и топ-100 global по позиции (~200 сайтов, вес 3 и 2).
- **Остальные 300** — ротацией: сайт с номером `i` идёт в ночь, когда `date.toordinal() % 7 == i % 7`, то есть ровно раз за любые 7 ночей (`plan --coverage` проверяет 500/500).
- `run --point ru|abroad` запускает план через `perf_audit.py --mode compat`. Точка только подписывает прогон: **машина и IP — решение владельца (COMPAT-BIZ)**. Живой прогон требует окна на переднем плане (`docs/ci-offload.md` §10).

Первая база CPR-RU / CPR-Global с двух точек — COMPAT-CORPUS-2-BASE (снята 2026-10-20, [журнал](journal.md)): abroad 5,9 % (RU 11,8 %, global 2,0 %), ru 15,2 % (RU 12,8 %, global 17,2 %). CPR-Global точки ru завышен симметричной гео-блокировкой — для global брать точку abroad.

## Пересборка

```
python scripts/corpus_c_build.py [--list-id <Tranco id>] [--workers 24]
python scripts/corpus_c.py check
```

Кэш проб — `.tmp/corpus-c/probe.json`. Сайт без записи в `corpus-c-categories.txt` получает категорию `?`, и `check` падает: допиши категорию.
