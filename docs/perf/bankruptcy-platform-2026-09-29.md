# Прогон Lumen по стенду bankruptcy-platform — 2026-09-29

Живая проверка локального стенда (Next.js 14 + Tailwind + Keycloak за nginx, `http://my-stand.local/`), вход `test_au`.
Проект стенда не менялся. Заведённые баги: [BUG-1217](../../bugs/BUG-1217-OPEN.md) … [BUG-1223](../../bugs/BUG-1223-OPEN.md).

## Условия

- Сборка: `cargo build -p lumen-shell --profile dev-release` от `main` 22a782d55 (5 мин 55 с). Первый прогон шёл на
  бинарнике от 2026-09-24 (466 коммитов позади) — результаты перепроверены на свежей сборке; расхождения:
  `document.scripts` (BUG-892) на свежей работает, ошибка календаря сменилась с `cssRules` на `insertRule`.
- Окно `--maximized`, 1920×945, `LUMEN_NO_ADBLOCK=1`, управление через `--mcp-live-port`.
- **Шум:** во время части прогонов на машине работали два чужих `rustc` (≈125 % и 115 % CPU при 8 ядрах). Абсолютные
  времена завышены; относительные доли не зависят.
- Сравнения с Chrome нет (эталон — только скриншот `arb465_after_login.png` из репозитория стенда).
