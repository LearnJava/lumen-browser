Объясни, как работает анти-фингерпринтинг в Lumen
Анти-фингерпринтинг в Lumen работает на нескольких уровнях:\n\n1. **Canvas fingerprint** — возвращается шумовое изображение вместо реального рендера\n2. **Audio context** — добавляется случайная задержка в обработку аудио\n3. **WebGL** — маскируется реальный renderer/vendor\n4. **Шрифты** — возвращается стандартный набор, скрывая установленные шрифты\n5. **Timezone/Language** — опциональная маскировка\n\nВсе эти техники делают ваш браузер неотличимым от тысяч других, что значительно усложняет отслеживание.
Сравни wgpu и skia для рендеринга UI
**wgpu** (WebGPU/Vulkan/Metal/DX12):\n- Низкоуровневый GPU API\n- Отличная производительность для кастомного рендера\n- Требует больше кода для базовых операций\n- Идеален для браузерного движка с собственным paint\n\n**Skia** (2D графическая библиотека):\n- Высокоуровневый API\n- Готовые примитивы (текст, пути, изображения)\n- Используется в Chrome, Flutter, Android\n- Меньше контроля, но быстрее разработка\n\nДля Lumen с собственным движком wgpu предпочтительнее — полный контроль над pipeline.
