Lumen — приватный лёгкий браузер с собственным движком на Rust

Как устроен собственный движок браузера

Пример страницы, открытой в новом окне. Загружено через потоковый пайплайн lumen-shell: HTML парсится инкрементально, CSS каскадируется в layout, вёрстка и отрисовка идут в отдельном потоке — окно не замирает на время загрузки.

Браузер — это не оболочка вокруг чужого движка, а единая система: ареновый DOM без Rc/RefCell, итераторный HTML-токенизатор, типизированный каскад CSS и собственный растеризатор. V8 исполняет JavaScript, остальное — код Lumen.

[Изображение-заглушка: движок рисует его через image-декодер]

Каждая навигация — будь то клик по ссылке, адресная строка или location.href из скрипта — проходит один и тот же потоковый конвейер вне UI-потока. Пользователь видит прогрессивные кадры вместо «замёрзшего» окна.

Приватность здесь не режим, а архитектура: shield-фильтр решает по каждому запросу в его собственном контексте, Tor — отдельный профиль без постоянного состояния, а Global Privacy Control выставляется только когда он не выдаёт отпечаток.

Дальше по тексту идут абзацы, чтобы у страницы была высота для прокрутки, восстановления позиции и find-in-page.

Вкладки группируются по цвету и названию, у каждой — свой контейнер (изоляция cookie и хранилищ), а закрытую можно вернуть по Ctrl+Shift+T со всей позицией прокрутки и состоянием.

История ищется полнотекстово (FTS5 + bm25), заметки и read-later доступны из той же адресной строки через @-префиксы — не нужно открывать отдельный раздел настроек.
