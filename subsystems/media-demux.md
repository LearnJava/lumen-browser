# lumen-media-demux ✅ (демуксеры MP4/fMP4, WebM/Matroska, Ogg без FFmpeg)

- **Scope:** UX-VIDEO-DEMUX ([ADR-035](../docs/decisions/ADR-035-media-decoding-without-ffmpeg.md) п.2). Крейт ничего не декодирует: отдаёт дорожки (`TrackInfo`: кодек, строка RFC 6381, `extradata` для декодера, размеры/частота/каналы) и поток пакетов (`Packet`: `pts`/`dts`/длительность в мкс, ключевой кадр, данные «как в контейнере»). Потребитель — бэкенды реестра декодеров (UX-VIDEO-NATIVE, OSDEC); в `crates/js`/`crates/shell` пока не подключён.
- **API:** `Demuxer::open(&[u8])` → `tracks()`, `duration_us()`, `next_packet()`, `seek_us()`. Ввод — байты в памяти (как у `VideoDecoder::open`).
- **MP4** — `mp4parse` читает таблицы `moov` (`stts/ctts/stsc/stsz/stco/stss`, `elst`, аудио-конфиги); `moof/traf/trun`, `trex`, `stsd` для `avc1/hvc1/hev1/av01/vp09` — свои (`mp4.rs`, `codec.rs`): `mp4parse` не знает HEVC/VP9/AV1 в `stsd`. fMP4 читается по всем фрагментам. `ctts` приводится к `pts ≥ dts` (минимум смещения вычитается, `pts` совпадает с ffprobe, `dts` может отличаться на постоянное смещение). `elst` с `media_time` сдвигает обе метки. Дорожки неизвестных кодеков (MPEG-4 Part 2 `mp4v`, `counting.mp4`) пропускаются — если других нет, `Unsupported`.
- **WebM/Matroska** — `matroska-demuxer`. Блок в `BlockGroup` не несёт флага ключевого кадра и читатель не отдаёт `ReferenceBlock` → признак берётся из данных (VP8/VP9/H.264/HEVC/AV1). Перемотка — **свой** индекс: `Cues`-перемотка читателя ищет первый кадр *после* метки и на `green-at-15.webm` отдаёт пустой поток, а видео надо начинать с ключевого кадра *до* цели; поэтому первая перемотка проходит файл и запоминает ключевые кадры видео, начало потока ищется пропуском кадров с начала файла (линейно по размеру файла, в памяти). Строка VP9/VP8 без параметров (`vp09`, `vp8`): `vpcC` в WebM нет.
- **Ogg** — `ogg` (страницы) + `lewton` (длительность Vorbis-пакетов по окнам); Vorbis, Opus (`OpusHead`, `pre_skip` не вычитается из меток), Theora, FLAC. Перемотка = перечитать с начала до пакета, покрывающего момент.
- **Сверка с ffprobe 9** (`examples/dump_packets.rs`, ноль расхождений по числу, размеру и признаку ключевого кадра пакетов на 30 файлах `tests/wpt/media` и фикстурах `tests/data`; `pts` — те же, кроме Opus: ffprobe вычитает `pre_skip`/`CodecDelay`, до 7 мс). Тесты — `src/tests.rs`.
- **Не делает:** MP3-файлы без контейнера (`UnknownContainer`), MPEG-TS, AVI, Matroska с шифрованием/субтитрами (дорожки пропускаются), потоковый ввод по частям.
- **Фикстуры `tests/data`** сделаны ffmpeg 9: `hevc.mp4` (hev1), `av1.mp4`, `frag.mp4` (fMP4), `bframes.mp4` (ctts), `opus.ogg`, `theora.ogv`; остальное — `tests/wpt/media`.
