# lumen-av1 ✅ (общий AV1-декодер: rav1d для AVIF и видео)

- **Scope:** UX-VIDEO-AV1 ([ADR-035](../docs/decisions/ADR-035-media-decoding-without-ffmpeg.md) п.2). Весь `unsafe` над C-ABI `dav1d_*` (rav1d) собран в одном месте; снаружи — безопасный потоковый `Decoder` и преобразование YUV→RGBA. Потребители: `lumen-image` (AVIF, `decode_still`) и, позже, бэкенд реестра UX-VIDEO-NATIVE (видео); в `crates/js`/`crates/shell` напрямую не подключён.
- **API:** `Decoder::new(&Config)` (`Config::still()` — один поток, ≤ 64 Мпикс; `Config::video()` — потоки по ядрам, автоглубина конвейера, ≤ 8K) → `send(temporal_unit, pts)` → `next_picture()`; `drain()` в конце потока, `flush()` при перемотке (следом идёт ключевой кадр). `Picture` — копия кадра: плоскости `u8`/`u16` без отступов, раскладка 4:0:0/4:2:0/4:2:2/4:4:4, 8/10/12 бит, диапазон, `matrix`/`primaries`/`transfer` по H.273, `pts` — метка, отправленная с пакетом. `decode_still(bytes, limit)` — AVIF и подобное.
- **Цвет:** `Picture::to_rgba8()` / `to_rgba8_into(&mut buf)` (буфер переиспользуется между кадрами) — фиксированная точка через таблицы по значению отсчёта, матрица (BT.709/601/2020/identity-GBR), limited/full, цветность — ближайший сосед, кадры ≥ 256 Кпикс делятся на потоки. `Picture::apply_alpha()` — отдельный альфа-элемент AVIF, с «распремножением».
- **Порядок и метки:** кадры выходят в порядке показа; `pts` (в мкс из `Packet::pts_us`) проходит через `Dav1dData::m.timestamp`. Скрытые кадры (altref) и `show_existing_frame` не дают лишних кадров.
- **asm:** фича `asm` (по умолчанию выключена; релиз — `lumen-shell --features av1-asm`, на x86 нужен nasm). Замер 1080p на машине разработчика: без asm ≈ 0,9× реального времени на 8 потоках, с asm ≈ 3,3× — [docs/perf/av1-decode.md](../docs/perf/av1-decode.md).
- **Тесты:** `src/tests.rs` — 17 штук; кадры 4:2:0 8/10/12 бит, 4:2:2 и 4:0:0 (`tests/data/clip_*.mp4`, ffmpeg 9 + libaom) побитово совпадают с эталоном ffmpeg/libdav1d (Adler-32 `framecrc`), RGBA — с независимой f64-формулой ±1, identity-матрица на `media-demux/tests/data/av1.mp4`, одно- и многопоточный выводы равны, `flush`, мусор вместо пакета, нечётные размеры, альфа.
- **Не делает:** воспроизведение (демукс → декодер → часы — UX-VIDEO-NATIVE), YUV на GPU без конвертации, ICC, HDR-тонмаппинг, слои масштабируемости (выдаётся старший пространственный слой), анимированный AVIF.
- **Пример:** `examples/bench.rs` — замер кадр/с на MP4/WebM с AV1.
